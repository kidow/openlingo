# Instructions

- Do not use TDD in this repository.
- Do not create new tests unless the user explicitly asks for tests.
- Do not modify existing tests unless it is strictly necessary for a user-requested change.

## Notes

- Notes must be written in Korean.
- Before adding new knowledge for a given language, check the corresponding document in `src/content/notes/` first.
- If needed, reorganize the existing content before applying the update.
- Keep only one notes file per language.
- If frontmatter exists, preserve `title`, `description`, `lang`, `createdAt`, and `updatedAt`.
- Whenever you update a notes document, make sure `updatedAt` is refreshed.
