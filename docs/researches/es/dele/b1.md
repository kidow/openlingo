# DELE B1 심층 가이드

> 중급 입문 등급. 독립 사용자(Independent User) 하위. 스페인어권 일반 생활·여행·업무 기본 수행.

## 1. 개요

주관: **Instituto Cervantes**, 출제·채점: **Universidad de Salamanca**. CEFR B1 대응.

## 2. B1 능력 정의

공식 **B1 능력 기준**:

- 업무·학교·여가 등 친숙 주제의 표준 언어 명확한 입력 요점 이해
- 스페인어권 국가 여행 중 발생 가능한 대부분 상황 대처
- 친숙·개인적 관심 주제의 간단·연결된 텍스트 산출
- 경험·사건·희망·계획 서술, 의견·계획 간단한 이유·설명 제시

## 3. 학습 범위

### 문법 핵심 (A2 위에 추가)
- **가정법 현재(Presente de subjuntivo)** 본격 학습 — 의지·의심·감정·평가·비인칭 구문
- **조건법 단순(Condicional simple)** — 공손, 가정, 조언
- **과거시제 4종 구분 숙달**: perfecto, indefinido, imperfecto, pluscuamperfecto
- 직·간접화법 (Estilo directo/indirecto)
- 관계절 (que, quien, donde, cuyo) 심화
- 수동태 (ser + 과거분사, se + 3인칭)
- 접속사·부사 확장: sin embargo, por lo tanto, a pesar de, en cambio
- 부정사·동명사·과거분사 복합 시제
- por vs para 정밀 구분
- 가정법 vs 직설법 선택 규칙

### 어휘 주제
사회 이슈, 매체·인터넷, 환경, 과학·기술 기초, 문화·예술, 직장·경력, 관계·감정 심화

### 누적 학습 시간
**약 350~400 수업시간** (제로 스타트).

## 4. 시험 구성

### 4개 pruebas

| Prueba | 내용 | 시간 |
|---|---|---|
| 1. Comprensión de lectura | 5개 과제, 30문항 | 70분 |
| 2. Comprensión auditiva | 5개 과제, 30문항 | 40분 |
| 3. Expresión e interacción escritas | 2개 과제 | 60분 |
| 4. Expresión e interacción orales | 4개 과제 | 15분 (+ 준비 15분) |

### 그룹 채점
- **Grupo 1**: 독해 + 작문 (50점)
- **Grupo 2**: 청해 + 구술 (50점)

### 문제 유형

**독해**: 기사·블로그·개인 텍스트 등 다양 장르 5종

**청해**: 대화·공지·뉴스·인터뷰·강연 발췌

**작문**:
1. 공식·비공식 서신·이메일 (100~120단어)
2. 기사·블로그·에세이 (130~150단어)

**구술**:
1. 주제 발표 (2~3분) — 시험 전 준비
2. 사진 상황 묘사·가설 (2~3분)
3. 사진 기반 대화
4. 실제 대화 시뮬레이션

## 5. 채점·합격 기준

- **총점**: 100점
- **합격**: 각 Grupo **30점 / 50점 이상**
- 결과: Apto / No apto

유효기간: 무기한.

## 6. 한국 응시 정보 (2026 기준)

### 시험장
서울(한국외대), 인천, 대구(대구가톨릭대).

### 2026 응시료
**B1: 254,000원** (2025 기준).

### 시험 일정
연 5~6회 중 B1 개최 회차 선택. 가장 많은 회차에 개설되는 레벨 중 하나.

### 활용
- **한국 대학 제2외국어 졸업 요건** 흔히 사용
- 스페인·라틴아메리카 어학연수 입학 기준
- **스페인 국적 신청** 자격(A2 이상이므로 B1도 충족)
- 스페인 대학 학부 입학 일부 기준 (다수는 B2 요구)

## 7. 학습 로드맵

1. **1~4주**: A2 취약점 복습, 가정법 현재 선행 학습
2. **5~24주**: B1 교재 (『Aula Internacional 3·4』, 『Nuevo Español en marcha B1』, 『Preparación DELE B1』)
3. **25~32주**: 가정법 용법 집중, 과거시제 4종 구분 훈련
4. **33~36주**: 공식 모델 6~8회분, 구술 과제별 스크립트 작성·암기
5. 시험 직전 2주: 타이머 모의고사, 작문 첨삭
