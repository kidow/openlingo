# DELE A1 Escolar 심층 가이드

> 11~17세 학령기 대상 적응형 시험. 일반 A1과 능력 수준 동일(CEFR A1), 주제·맥락을 학생 연령에 맞게 조정.

## 1. 개요

### Escolar 특징
- 대상: **11~17세** 학령기 학습자
- 주제·상황·어휘를 **학교·가족·또래·여가** 등 청소년 생활권으로 조정
- 능력 기준은 일반 DELE A1과 동일 (CEFR A1)
- 학위는 **DELE A1**(일반 A1)과 동등한 효력 — 단 "Escolar" 표기
- 주관: **Instituto Cervantes**, 출제·채점: **Universidad de Salamanca**

### Escolar 시험 체계
- **A1 Escolar**
- **A2/B1 Escolar** (단일 시험으로 A2 또는 B1 판정)
- B2/C1 Escolar (일부 지역·공식 페이지 언급, 상설 시행 여부는 지역별 상이)

## 2. A1 Escolar 능력 정의

일반 A1과 동일 — CEFR A1:

- 개인 정보, 친숙한 주제 기본 표현 이해·사용
- 자기소개, 가족·친구·학교·취미 관련 질의응답
- 상대가 천천히 명확히 말하면 간단 소통 가능

학령기 맥락: 학교생활, 교실 수업, 가족, 또래 친구, 취미·스포츠, 생일, 여행, 인터넷 기초 사용 등.

## 3. 학습 범위

### 문법 핵심 (일반 A1과 동일)
- 성·수 일치
- 관사 (el/la, un/una)
- 동사 ser/estar/tener/haber 현재
- 규칙·주요 불규칙 동사 현재
- 재귀동사 기초
- 의문사, gustar, 기초 전치사
- 현재시제 중심

### 어휘 주제 (학령기 특화)
학교·교실, 과목, 시간표, 가족·친척, 친구, 또래 활동, 취미·게임·스포츠, 음식·점심, 생일·파티, 옷·학용품, 신체·건강, 날씨, 컴퓨터·인터넷 기초

### 누적 학습 시간
일반 A1과 동일 — **약 60~80 수업시간**.

## 4. 시험 구성

### 4개 pruebas (일반 A1과 동일 구조, 주제 조정)

| Prueba | 내용 | 시간 |
|---|---|---|
| 1. Comprensión de lectura | 4개 과제, 25문항 | 45분 |
| 2. Comprensión auditiva | 4개 과제, 25문항 | 25분 |
| 3. Expresión e interacción escritas | 2개 과제 | 25분 |
| 4. Expresión e interacción orales | 4개 과제 | 15분 (+ 준비 10분) |

### 그룹 채점
- **Grupo 1**: 독해 + 작문 (50점)
- **Grupo 2**: 청해 + 구술 (50점)

### 주제 차이
텍스트·대화·사진이 **청소년 일상**(학교·친구·스포츠·게임 등) 중심. 성인 A1은 직장·성인 일상 비중 포함.

### 문제 유형
일반 A1과 동일 (양식·메시지·사진 묘사·시뮬레이션 대화).

## 5. 채점·합격 기준

- **총점**: 100점
- **합격**: 각 Grupo **30점 / 50점 이상**
- 결과: Apto / No apto

### 유효기간
무기한. 학위는 **"Diploma DELE A1 para Escolares"** 명칭이나 A1 자격 자체는 동등.

## 6. 한국 응시 정보 (2026 기준)

### 시험장
서울(한국외대), 인천, 대구(대구가톨릭대) — 일반 DELE와 공통. Escolar 시행 회차는 별도 공지 확인.

### 2026 응시료
**A1 Escolar: 166,000원** (2025 기준, 일반 A1과 동일).

### 시험 일정
연 1~2회 개최. 일반 DELE보다 회차 수 적음 — 공식 공지 확인 필수.

### 활용
- 국내 스페인어 조기 학습자 성취 인증
- 스페인·라틴아메리카 국제학교·교환학생 지원 기초선
- 한국 외고·국제고 스페인어 선택 학생 대외 스펙

## 7. 학습 로드맵

1. **1~4주**: 알파벳·발음·기초 표현 (교재 권장: 『Los Trotamundos A1』, 『Colega 1·2』 — 청소년 특화)
2. **5~16주**: 청소년 대상 A1 교재 전과
3. **17~20주**: 공식 Escolar 모델 시험 2~3회분 (examenes.cervantes.es)
4. **21~22주**: 구술 모의 — 학교·또래 주제 중심 스크립트 준비
