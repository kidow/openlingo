# DELE A2/B1 Escolar 심층 가이드

> 11~17세 학령기 대상. **단일 시험으로 A2 또는 B1 판정** — 레벨 결정을 시험 결과에 위임하는 독특한 구조.

## 1. 개요

### Escolar 특징
- 대상: **11~17세** 학령기
- 주제·상황·어휘를 **청소년 생활권**으로 조정
- 능력 기준은 CEFR A2 및 B1
- **하나의 시험지로 응시 후 점수에 따라 A2 또는 B1 학위 수여** (또는 불합격)
- 주관: **Instituto Cervantes**, 출제·채점: **Universidad de Salamanca**

### 판정 로직
- **높은 점수**: DELE B1 para Escolares 학위
- **중간 점수**: DELE A2 para Escolares 학위
- **낮은 점수**: No apto (불합격)

구체 컷오프는 공식 고시 채점 기준 적용. 응시자는 사전에 목표 레벨 선택하지 않고 성취도에 따라 사후 결정됨.

## 2. 능력 정의

### A2 (CEFR A2)
일상 경험 영역(가족·쇼핑·지역·학교) 빈번한 표현 이해. 친숙·일상 주제 간단 직접 정보 교환. 과거·현재·계획 간단 서술.

### B1 (CEFR B1)
학교·여가·친숙 주제 표준 언어 요점 이해. 여행 중 대부분 상황 대처. 친숙 주제 연결된 텍스트 산출. 경험·사건·계획·의견 서술.

학령기 맥락 예: 학교생활, 또래 관계, 가족, 여행, 취미·스포츠, 매체·인터넷·SNS, 환경, 기술, 간단 시사 이슈.

## 3. 학습 범위

### A2 문법 핵심
- 과거시제: pretérito perfecto, indefinido, imperfecto 기초
- 미래시제 (ir a + 부정사, futuro simple)
- 직·간접목적격 대명사
- 비교·최상급
- 명령법 긍정

### B1 문법 핵심 (추가)
- **가정법 현재(Presente de subjuntivo)** — 의지·의심·감정·비인칭
- 조건법 단순
- 과거시제 4종 정밀 구분
- 직·간접화법
- 관계절 심화
- 수동태 (ser + 과거분사, se 수동)
- por vs para

### 어휘 주제 (학령기 특화 확장)
학교·진로·직업 탐색, 또래·우정·갈등, 가족 관계, 여행·문화 체험, 매체·SNS·인터넷, 환경·기후변화 기초, 건강·운동, 감정·성격, 취미·예술·음악

### 누적 학습 시간
**180~400 수업시간** (목표 레벨에 따라).

## 4. 시험 구성

### 4개 pruebas — B1 수준 기준 구조

| Prueba | 내용 | 시간 |
|---|---|---|
| 1. Comprensión de lectura | 5개 과제 | 약 55분 |
| 2. Comprensión auditiva | 5개 과제 | 약 30분 |
| 3. Expresión e interacción escritas | 2개 과제 | 약 50분 |
| 4. Expresión e interacción orales | 4개 과제 | 약 12분 (+ 준비) |

※ 구체 시간·과제 수는 공식 모델 확인. B1 성인판 대비 약간 짧거나 조정될 수 있음.

### 그룹 채점
- **Grupo 1**: 독해 + 작문
- **Grupo 2**: 청해 + 구술

### 주제 차이
청소년 관점·맥락 — 학교생활, 또래, 디지털 환경, 청소년 관심 주제.

### 문제 유형

**독해**: 학교 공지·친구 메시지·블로그·청소년 잡지 기사

**청해**: 라디오·팟캐스트 청소년 판, 대화, 인터뷰

**작문**:
1. 개인·비공식 서신·이메일
2. 블로그·SNS 포스트·짧은 기사

**구술**:
1. 주제 독백 (준비 후)
2. 사진·상황 묘사·가정
3. 사진 기반 대화
4. 시뮬레이션 대화

## 5. 채점·합격 기준

### 배점·판정 체계
- **총점**: 100점
- **각 Grupo**: 50점
- **B1 수여**: 상위 점수 구간 + 각 Grupo 최소 기준 충족
- **A2 수여**: 중간 점수 구간 + 각 Grupo 최소 기준 충족
- **No apto**: 기준 미달

※ 정확한 A2/B1 컷오프는 공식 채점 기준 (세르반테스 자료). 응시 전 최신 자료 확인 권장.

### 유효기간
무기한. 학위는 **"Diploma DELE A2 para Escolares"** 또는 **"Diploma DELE B1 para Escolares"**로 수여.

## 6. 한국 응시 정보 (2026 기준)

### 시험장
서울(한국외대), 인천, 대구(대구가톨릭대) — 일반 DELE와 공통. Escolar 시행 회차 별도 공지 확인.

### 2026 응시료
**A2/B1 Escolar: 254,000원** (2025 기준, 일반 B1과 동일).

### 시험 일정
연 1~2회. 일반 DELE 회차 중 일부에 시행. 공식 공지 필수.

### 활용
- 국내 청소년 스페인어 학습 공식 성취 인증
- **스페인·라틴아메리카 교환학생·유학 지원**
- 한국 외고·국제고·특목고 스페인어 스펙
- 스페인어권 국제학교 입학 요건
- A2 수여 시 스페인 청소년 국적·체류 일부 프로세스 지원

## 7. 학습 로드맵

### B1 목표
1. **1~4주**: A2 기초 완성 점검, 가정법 현재 선행
2. **5~28주**: 청소년 특화 B1 교재 (『Los Trotamundos B1』, 『Nuevo Chicos Chicas B1』, 『Preparación DELE A2/B1 Escolar』)
3. **29~36주**: 과거시제 정밀 구분, 가정법 용법 체화
4. **37~40주**: 공식 Escolar 모델 4~5회분, 구술 청소년 주제별 스크립트

### A2 목표 (더 짧은 기간)
1. **1~20주**: A2 완성 교재 중심
2. **21~24주**: 공식 모델 2~3회분

### 권장 보조 자료
- 청소년 대상 스페인어 팟캐스트: 《Spanish Obsessed》, 《Español con Juan》
- YouTube 스페인어권 청소년 크리에이터
- 스페인·라틴아메리카 청소년 드라마 (Netflix 스페인어 콘텐츠)
