# DELE A2 심층 가이드

> Diplomas de Español como Lengua Extranjera 초급 상위 등급. 기초 일상 의사소통.

## 1. 개요

주관: **Instituto Cervantes**, 출제·채점: **Universidad de Salamanca**. CEFR A2 대응. 학위 무기한 유효. 상세는 [A1 문서](./a1.md) 참조.

### A2 특수 활용
**스페인 국적 취득 요건** 중 하나 — 2015년 이후 스페인 시민권 신청자는 DELE A2 이상 + CCSE (문화·사회 상식 시험) 통과 필요.

## 2. A2 능력 정의

공식 **A2 능력 기준**:

- 일상 경험 영역(가족·구매·직장·근교 등)의 빈번한 표현·문장 이해
- 익숙·일상 화제에서 간단·직접적인 정보 교환이 필요한 의사소통 수행
- 과거·현재·계획된 미래 활동의 간단한 서술 가능

## 3. 학습 범위

### 문법 핵심 (A1 위에 추가)
- 과거시제: **Pretérito perfecto** (he comido), **Pretérito indefinido** (comí), **Pretérito imperfecto** (comía) 기초
- 미래시제: ir a + 부정사, futuro simple
- 직접·간접목적격 대명사: lo, la, le, les
- 재귀동사 확장
- 비교급·최상급: más/menos que, tan... como, el/la más...
- 명령법 기초 (긍정 명령)
- 가정법 현재 기초 인식 (생산은 B1 이상)
- 접속사: porque, cuando, si (조건), aunque, pero, también/tampoco
- 관사·대명사 용법 심화

### 어휘 주제
A1 주제 확장 + 쇼핑, 여행, 호텔, 레스토랑, 건강·병원, 취미·여가, 감정·성격, 교육·학업

### 누적 학습 시간
**약 180~200 수업시간** (제로 스타트).

## 4. 시험 구성

### 4개 pruebas

| Prueba | 내용 | 시간 |
|---|---|---|
| 1. Comprensión de lectura | 5개 과제, 30문항 | 60분 |
| 2. Comprensión auditiva | 5개 과제, 30문항 | 40분 |
| 3. Expresión e interacción escritas | 3개 과제 | 50분 |
| 4. Expresión e interacción orales | 4개 과제 | 12분 (+ 준비 12분) |

### 그룹 채점
- **Grupo 1**: 독해 + 작문 (각 25점, 합 50점)
- **Grupo 2**: 청해 + 구술 (각 25점, 합 50점)

### 문제 유형

**독해**: 광고·공지·기사·개인 서신 등 5종 텍스트 독해

**청해**: 공지·대화·뉴스·인터뷰 등 일상 담화

**작문**:
1. 개인 서신·이메일 (60~70단어)
2. 일지·블로그·기사 (70~80단어)
3. 양식 채우기 또는 짧은 메시지

**구술**:
1. 친숙한 주제 독백 (3~4분)
2. 사진 묘사
3. 사진 기반 대화
4. 면접관과 시뮬레이션 대화

## 5. 채점·합격 기준

- **총점**: 100점
- **합격**: 각 Grupo **30점 / 50점 이상** 동시 충족
- 결과: Apto / No apto

유효기간: 무기한.

## 6. 한국 응시 정보 (2026 기준)

### 시험장
- 서울 (한국외대), 인천, 대구(대구가톨릭대)
- 주관: 주한 세르반테스 문화원

### 2026 응시료
**A2: 215,600원** (2025 기준, 2026 공식 공지 재확인)

### 시험 일정
연 5~6회 중 A2 개최 회차 선택. 각 회차 A2 시행 여부 공식 사이트 확인.

### 특수 목적
스페인 국적 신청 수단 — A2 + CCSE 조합. DELE A2는 언어 인증, CCSE는 스페인 사회·문화·헌법 지식 시험(별도).

## 7. 학습 로드맵

1. **1~4주**: A1 완성 복습, 과거시제 2종(perfecto/indefinido) 선행
2. **5~16주**: A2 교재 (『Aula Internacional 2』, 『Nuevo Español en marcha A2』) 전과
3. **17~22주**: 과거시제 용법 구분 집중 (perfecto vs indefinido vs imperfecto)
4. **23~26주**: 공식 모델 시험 4~5회분, 구술 모의 연습
