# DALF C1 심층 가이드

> DALF(Diplôme approfondi de langue française) 하위 등급. 숙련 사용자(Utilisateur expérimenté) 하위. 프랑스 대학원 일반 기준.

## 1. 개요

주관: **France Éducation International**. CEFR C1 대응. DELF와 별개 학위(DALF)로 수여 — 고급 이상은 "DELF"가 아닌 "DALF" 명칭.

학위 무기한, 프랑스 교육부 인정.

## 2. C1 능력 정의

공식 **C1 능력 기준**:

- 광범위·요구도 높은 장문 텍스트 암시적 의미까지 이해
- 뚜렷한 단어 검색 없이 유창·자발적 표현
- 사회·학술·전문 목적 언어 유연·효과적 사용
- 복잡 주제 명확·잘 구조화된·상세한 텍스트 산출 — 연결사·결속 장치 숙련 사용

## 3. 학습 범위

### 문법·언어 운용 핵심
- 전 문법 체계 숙달 + 미묘한 뉘앙스 구분
- 문어체·격식체 vs 구어체·비격식체 정밀 선택
- 수사법 (métaphore, métonymie, ironie, euphémisme, litote)
- 고급 관용 표현·속담·**콜로케이션**
- 담화 구조·일관성·응집성 장치
- 다양한 등록(registre) 조절: 학술, 법률, 경제, 문학, 저널리즘
- Subjonctif imparfait 인식·독해 (문학 원전)
- 고전·고급 문학 표현 식별

### 어휘 주제
추상 사상·철학, 사회학·심리학, 경제·금융, 법률·행정, 과학·의학 기초, 문학·예술 비평, 역사·정치, 국제 관계

### 누적 학습 시간
**약 700~800 수업시간**.

## 4. 시험 구성

### 4개 épreuves

| Épreuve | 시간 |
|---|---|
| 1. Compréhension de l'oral | 40분 |
| 2. Compréhension des écrits | 50분 |
| 3. Production écrite | **2시간 30분** |
| 4. Production orale | 30분 (+ 준비 1시간) |

총 집단 시험 **4시간** + 구술 30분 (준비 1시간).

### 문제 유형

**청해**:
- 긴 녹음 (인터뷰·강연·라운드테이블) — 2회 청취
- 짧은 녹음 여러 개 — 1회 청취

**독해**:
- 장문 복잡 텍스트 (기사·에세이·문학 발췌)

**작문 (Production écrite) — 2개 과제 통합**:
1. **Synthèse de documents** (문서 종합) — 약 220단어
   - 복수 문서 주제·논점 종합
   - 본인 의견 금지, 객관적 재구성
2. **Essai argumenté** (논증 에세이) — 약 250단어 이상
   - Synthèse와 동일 주제 관련 논증

권장 시간 배분: Synthèse 1시간 30분 + Essai 1시간.

**구술 (Production orale) — 2개 과제**:
1. **Exposé** (발표) — 자료 2~3개 종합 후 10~15분 본인 입장 발표
2. **Débat** (토론) — 시험관과 10~15분 심화 토론

준비 시간 1시간 (자료 독해·발표 개요 구성).

## 5. 채점·합격 기준

- 총점 100점 (25 × 4)
- **합격**: 50/100 이상
- **실격**: 한 épreuve 5점 미만 — 총점 무관 불합격

유효기간: 무기한.

## 6. 한국 응시 정보 (2026)

### 응시료
**C1: 330,000원**

### 시험장
서울(알리앙스프랑세즈 주 개설지), 부산, 대전 등 — C1은 회차별 개설 여부 확인 필수.

### 시험 일정
연 2~3회 중 C1 개최 회차 (통상 5월·11월 중심).

### 주요 활용
- **프랑스 대학원(Master·Doctorat) 지원 일반 요건**
- **프랑스 의료·법무 면허 인증** 요건
- **Campus France** 고급 과정 지원
- 프랑스어권 학술·연구직 지원
- 한국 대학 프랑스어 전공 교원 임용
- **국제 통번역 대학원** 지원
- **유네스코·UN·EU 기구 프랑스어 실무자** 기준 접근선
- 퀘벡·벨기에·스위스 전문직 인증

## 7. 학습 로드맵

1. **1~8주**: B2 취약점 복습, 고급 담화 표지·등록 구분 학습
2. **9~40주**: C1 교재 (『Réussir le DALF C1-C2』, 『Réussir le nouveau DALF C1』, 『ABC DALF C1』)
3. **41~52주**: 학술 논문·Le Monde diplomatique·문학 원전 정독, France Culture 팟캐스트 청취
4. **53~64주**: 공식 모델 + 기출 10회분, Synthèse 훈련 집중 (요약·재구성)
5. 시험 직전 6주: 타이머 모의고사, 작문·구술 첨삭 주 2회

### 권장 보조 자료
- Le Monde diplomatique, L'Obs, Le Point 논설·오피니언
- France Culture, France Inter 시사 프로그램
- 현대 프랑스 문학: Houellebecq, Modiano, Ernaux, Le Clézio, Echenoz
- 학술: Annales, Esprit, Critique
