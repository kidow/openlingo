# DELF A1 심층 가이드

> Diplôme d'études en langue française (DELF) 최하위 등급. 프랑스어 입문자 대상.

## 1. DELF / DALF 개요

### 주관
**France Éducation International (FEI)** (구 CIEP — Centre international d'études pédagogiques). **프랑스 교육부** 명의로 공식 학위 발급.

### 체계
- **DELF**: 4개 레벨 A1·A2·B1·B2 (Diplôme d'études en langue française)
- **DALF**: 2개 레벨 C1·C2 (Diplôme approfondi de langue française)
- CEFR 전 6단계 대응

### 버전 체계
- **DELF Tout Public** (일반 성인): A1·A2·B1·B2
- **DELF Junior / Scolaire** (11~17세 청소년): A1·A2·B1·B2
- **DELF Prim** (초등 7~12세): A1.1·A1·A2
- **DELF Pro** (직업 목적): A1·A2·B1·B2
- **DALF** (고급 성인): C1·C2

※ 모든 버전 학위 **가치 동등**. 주제만 대상 연령·맥락에 맞게 조정.

### 학위 특성
- **유효기간 무기한** (평생)
- 국제적 인정 — 프랑스 대학 입학, 프랑스 국적 신청, 취업·이민 공식 인정
- 2020 포맷 개편 (A1·A2·B1 일부 조정)

## 2. A1 능력 정의

공식 **A1 능력 기준** (CEFR A1):

- 일상 극히 친숙한 표현·기본 문장 이해·사용
- 자기·타인 소개, 거주지·아는 사람·소유물 등 개인 정보 질의응답
- 상대가 천천히·명확히 말하고 도움 주면 간단 소통 가능

## 3. 학습 범위

### 문법 핵심
- 관사: articles définis (le/la/les), indéfinis (un/une/des), partitifs (du/de la/des)
- 명사 성·수 (genre, nombre)
- 주격 대명사: je, tu, il/elle, on, nous, vous, ils/elles
- 동사 être / avoir / aller / faire 현재
- 1군 동사 (-er) 현재 규칙 변화
- 주요 2군·3군 불규칙 동사: finir, venir, pouvoir, vouloir, prendre, savoir
- 부정문: ne...pas
- 의문문 3가지 형식: intonation, est-ce que, 도치
- 의문사: qui, que, où, quand, comment, pourquoi, combien
- 소유형용사: mon/ma/mes, ton/ta/tes, son/sa/ses
- 지시형용사: ce/cet/cette/ces
- 기초 전치사: à, de, en, dans, sur, sous, avec, pour
- 숫자 1~1000

### 어휘 주제
인사·소개, 숫자·날짜·요일·월·시간, 가족, 국적, 직업, 색깔, 음식·음료, 신체, 옷, 집·가구, 교통, 날씨, 일상 동작

### 누적 학습 시간
CEFR 권장 **약 60~100 수업시간** (제로 스타트).

## 4. 시험 구성

### 4개 épreuves (시험)

| Épreuve | 내용 | 시간 |
|---|---|---|
| 1. Compréhension de l'oral | 4개 과제 | 20분 |
| 2. Compréhension des écrits | 4개 과제 | 30분 |
| 3. Production écrite | 양식 + 간단 메시지 | 30분 |
| 4. Production orale | 3개 과제 (인터뷰·정보 교환·시뮬레이션 대화) | 5~7분 (+ 준비 10분) |

**집단 시험(3 epreuves)**: 청해·독해·작문 = 약 1시간 20분 (같은 날)
**개별 시험**: 구술 — 별도 일정

### 문제 유형

**청해**: 짧은 공지·메시지·대화 (2회 청취, 최대 3분)

**독해**: 짧은 공지·양식·메모·이메일

**작문**:
- 양식 채우기 (개인 정보)
- 엽서·짧은 메시지 (40~50단어)

**구술**:
1. 안내된 대화 (Entretien dirigé) — 자기소개
2. 정보 교환 (Échange d'informations)
3. 역할극 (Dialogue simulé / Jeu de rôle)

## 5. 채점·합격 기준

### 배점
- 각 épreuve **25점** × 4 = **총 100점**

### 합격 조건
1. **총점 50점 / 100점 이상**
2. **한 épreuve라도 5점 미만이면 실격(éliminatoire)** — 총점 무관 불합격

### 유효기간
무기한.

## 7. 학습 로드맵

1. **1~4주**: 알파벳·발음·악센트(é/è/ê/à)·연음(liaison)·기본 표현
2. **5~12주**: A1 교재 (『Édito A1』, 『Cosmopolite 1』, 『Alter Ego + A1』)
3. **13~16주**: 공식 모델 시험지 (France Éducation International 사이트) 4~5회분
4. **17~18주**: 구술 모의 연습 (파트너 또는 언어교환)
