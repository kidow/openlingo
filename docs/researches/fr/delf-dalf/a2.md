# DELF A2 심층 가이드

> DELF 초급 상위 등급. 기초 일상 의사소통.

## 1. 개요

주관: **France Éducation International (FEI)**. 프랑스 교육부 명의. CEFR A2 대응. 학위 무기한. 상세는 [A1 문서](./a1.md) 참조.

### 2020 포맷 개편
A2는 2020년 포맷 개편 적용 — 일부 과제 유형·시간 조정.

## 2. A2 능력 정의

공식 **A2 능력 기준**:

- 일상 경험 영역(가족·쇼핑·근교·직장) 빈번 표현·문장 이해
- 익숙·일상 화제 간단·직접 정보 교환 의사소통
- 과거·현재·계획된 미래 활동 간단 서술

## 3. 학습 범위

### 문법 핵심 (A1 위에 추가)
- 과거시제: **passé composé**, **imparfait** 기초
- 미래시제: **futur proche** (aller + 부정사), **futur simple**
- 직접·간접목적격 대명사: me/te/le/la/nous/vous/les, lui/leur
- y, en (장소·부분·불특정)
- 재귀동사 본격 (se lever, se coucher, se promener)
- 비교급·최상급: plus/moins/aussi... que, le/la/les plus...
- 조건법 현재 (시제 없이 공손 표현: je voudrais, j'aimerais)
- 명령법
- 관계대명사 qui, que 기초
- 부정 확장: ne...plus, ne...jamais, ne...rien, ne...personne

### 어휘 주제
A1 확장 + 쇼핑, 여행, 호텔, 레스토랑, 건강·병원, 취미·여가, 감정·성격, 교육·학업

### 누적 학습 시간
**약 200 수업시간**.

## 4. 시험 구성

### 4개 épreuves

| Épreuve | 시간 |
|---|---|
| 1. Compréhension de l'oral | 25분 |
| 2. Compréhension des écrits | 30분 |
| 3. Production écrite | 30분 |
| 4. Production orale | 6~8분 (+ 준비 10분) |

총 집단 시험 약 1시간 40분 + 구술.

### 문제 유형

**청해**: 짧은 대화·공지·메시지 (2회 청취)

**독해**: 광고·공지·짧은 기사·메시지 등 다양 장르

**작문**:
- 짧은 기록·일기 (편지·이메일 1개) — 60~80단어
- 짧은 개인 경험 서술 또는 응답 — 60~80단어

**구술**:
1. 안내된 대화 (Entretien dirigé)
2. 독백 (Monologue suivi) — 주제 발표
3. 역할극 (Exercice en interaction)

## 5. 채점·합격 기준

- 총점 100점 (25 × 4)
- **합격**: 50/100 이상
- **실격**: 한 épreuve 5점 미만 시 총점 무관 불합격

유효기간: 무기한.

## 6. 한국 응시 정보 (2026)

### 응시료
**A2: 190,000원**

### 시험장
서울(알리앙스프랑세즈), 부산, 대전, 광주, 인천, 대구.

### 시험 일정
연 4~6회 중 A2 개최 회차 — 공식 공지.

### 특수 활용
**프랑스 국적 신청** 기초 요건 중 하나. 2011년 이후 프랑스 시민권 신청자 DELF B1 요구로 상향됐으나 일부 경로(장기체류·결혼 이민 등)는 A2 수용.

## 7. 학습 로드맵

1. **1~4주**: A1 완성 복습, passé composé 선행
2. **5~16주**: A2 교재 (『Édito A2』, 『Cosmopolite 2』)
3. **17~22주**: 과거시제 2종(passé composé / imparfait) 용법 집중
4. **23~26주**: 공식 모델 4~5회분, 구술 모의
