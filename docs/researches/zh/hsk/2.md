# HSK 3.0 2급 심층 가이드

> 한어수평고시 신표준(HSK 3.0) 초등 단계 2번째 급수. 생활 기본 의사소통 입문.

## 1. HSK 3.0 개요

《国际中文教育中文水平等级标准》(GF0025-2021) 기반. 2021-07-01 공식 실시, **2026-07 전면 시행 예정**. 주관: 중외어언교류합작센터(CLEC) / CTI.

3단9급 체계 — 초등(1~3급), 중등(4~6급), 고등(7~9급). 4차원 기준: 음절·한자·어휘·문법.

상세 개요는 [1급 문서](./1.md) 참조.

## 2. 2급 능력 정의

공식 **2급 능력 기준**:

- 일상생활·학습의 친숙한 화제에서 간단한 의사소통 가능
- 매우 친숙한 주제의 간결한 대화 이해 및 참여
- 기본적인 개인 정보, 일상 활동, 간단한 감정·의견 표현
- 간단한 안내문·표지 이해

CEFR 대략 A1 상위 ~ A2 초반 수준.

## 3. 학습 범위 (공식 정량)

| 항목 | HSK 3.0 2급 | (참고) HSK 2.0 2급 |
|---|---|---|
| 음절 | 468개 (누적) | — |
| 한자 (인식) | 600자 (누적) | 349자 |
| 한자 (쓰기) | ~300자 (누적) | — |
| 어휘 | 1,272단어 (누적) | 300단어 |
| 문법 항목 | 129개 (누적) | 약 30개 |

### 1급 대비 핵심 추가
- **문법**:
  - 조동사: 会/能/可以/想/要/应该
  - 비교 표현: 比자문 기초 (A 比 B + 형용사)
  - 연동문: 去/来 + 동사, 동사 + 동사
  - 시량보어 / 동량보어 기초 (一下, 一会儿)
  - 「了」 심화 (완료 了₁, 변화 了₂)
  - 「过」 경험 표현
  - 在 + 장소 (진행형 在 + 동사)
  - 정도부사: 很/非常/太/真
- **어휘 주제**: 날씨, 교통, 쇼핑 확장, 건강·신체, 직업, 감정(高兴/难过/累)
- **한자**: 부수 체계화, 형성자(形声字) 원리

### 누적 학습 시간
업계 추정 **300~400시간** (제로 스타트 누적).

## 4. 시험 구성

### 개요
- **문항 수**: 약 60문항
- **총 시간**: 약 60분
- **평가 영역**: 듣기 + 읽기 + **쓰기(신규)**
- **형식**: IBT / PBT

### 섹션 구성

| 섹션 | 문항 수 | 시간 |
|---|---|---|
| 듣기 | 30문항 | ~25분 |
| 읽기 | 20문항 | ~22분 |
| 쓰기 | 10문항 | ~13분 |

※ HSK 3.0에서 2급에 **쓰기 섹션 신설** — HSK 2.0 대비 큰 변화.

### 문제 유형

**듣기**
- 1부: 사진 판단 (✓/✗)
- 2부: 짧은 대화 — 사진 선택
- 3부: 짧은 대화 — 객관식
- 4부: 짧은 대화 — 객관식 (길이 증가)

**읽기**
- 1부: 문장-사진 매칭
- 2부: 빈칸 채우기
- 3부: 짧은 대화 매칭
- 4부: 짧은 지문 이해

**쓰기**
- 1부: 어순 배열 (주어진 단어로 문장 완성) — 5문항
- 2부: 빈칸에 맞는 한자 써넣기 (병음 제공) — 5문항

## 5. 채점·합격 기준

### 배점

| 섹션 | 배점 |
|---|---|
| 듣기 | 100점 |
| 읽기 | 100점 |
| 쓰기 | 100점 |
| **총점** | **300점** |

### 합격 조건
**총점 180점 / 300점 이상** (60%).

섹션별 최소 기준점 공식 미규정 (3.0 기준 공식 최종 고시 확인 권장).

### 성적 유효기간
2년.

## 7. 학습 로드맵 예시

1. **1~4주**: 1급 취약점 복습, 한자 쓰기 기본 획순·부수 완성
2. **5~16주**: 2급 교재 (『HSK Standard Course 2』 등) 1~15과
3. **17~22주**: 어휘 1,272 완성, 문법 129 패턴 예문 외우기
4. **23~26주**: 공식 샘플 + 기출, 쓰기(어순 배열·한자 쓰기) 집중

## 9. 신뢰도·한계

- **고신뢰**: 3단9급 체계, 합격 총점 기준, 한국 시행기관.
- **중신뢰**: 섹션별 문항 수, 시간 배분, 한국 응시료.
- **저신뢰**: 4차원 정량 수치 — 소스 간 편차 존재 (공식 대강 수치 우선 기재).
- **미확정**: HSK 3.0 전면 시행 후 섹션별 기준점 도입 여부, 2급 쓰기 신설 최종 확정 범위.
