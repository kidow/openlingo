# HSK 3.0 4급 심층 가이드

> 한어수평고시 신표준(HSK 3.0) 중등 단계 진입 급수. 실용적 의사소통 본격 수준.

## 1. HSK 3.0 개요

《国际中文教育中文水平等级标准》(GF0025-2021) 기반. 2021-07-01 실시, **2026-07 전면 시행 예정**. 주관: CLEC / CTI.

**중등 단계(4~6급) 진입선**. 이 단계부터 번역 기능이 공식 학습 목표에 포함.

## 2. 4급 능력 정의

공식 **4급 능력 기준**:

- 다양한 생활·학습·업무 장면에서 비교적 유창한 의사소통 수행
- 중국에서의 일반 사회 활동에 필요한 언어 운용
- 논리적 서술, 비교·설명·주장 전개
- 신문·잡지 일반 기사, 간단한 설명문 이해
- 짧은 보고서·편지·이메일 작성
- 간단한 번역 기초 (중↔외, 구두 및 서면)

CEFR 대략 B1 수준.

## 3. 학습 범위 (공식 정량)

| 항목 | HSK 3.0 4급 | (참고) HSK 2.0 4급 |
|---|---|---|
| 음절 | 724개 (누적) | — |
| 한자 (인식) | 1,200자 (누적) | 1,064자 |
| 한자 (쓰기) | ~900자 (누적) | — |
| 어휘 | 3,245단어 (누적) | 1,200단어 |
| 문법 항목 | 286개 (누적) | 약 120개 |

### 3급 대비 핵심 추가
- **문법 심화**:
  - 「把」자문 심화 (결과·방향·양상)
  - 「被」자문 심화 (수동·피해·무의지)
  - 복합 보어 (동사 + 결과 + 방향)
  - 복문 확장: 병렬(不但...而且), 역접(尽管...还是), 가정(即使...也, 哪怕...也), 조건(只要...就, 只有...才), 양보, 선택(不是...就是, 要么...要么)
  - 「着」 상태 지속
  - 「来/去」 추상 방향
  - 「以...为...」, 「对...来说」, 「关于」, 「至于」, 「对于」, 「由于」 등 허사·관용 구문
  - 강조·초점: 「连...也/都...」, 「无论...都...」
  - 어기조사 심화: 吧/呢/啊/嘛/呗
- **어휘 주제**: 사회·문화 일반, 환경, 기술, 매체, 경제·취업 기초, 추상 개념(自由/机会/成功/失败)
- **성어·관용 표현**: 기초 사자성어, 속담, 헐후어 일부
- **번역 기초**: 구두 통역(중↔모국어) 입문

### 누적 학습 시간
업계 추정 **1,000~1,500시간** (제로 스타트 누적).

## 4. 시험 구성

### 개요
- **문항 수**: 약 70문항 (HSK 2.0의 100문항에서 감소)
- **총 시간**: 약 85분
- **평가 영역**: 듣기 + 읽기 + 쓰기
- **HSK 3.0 4급 신규**: **번역 기능** 시험 범위에 진입 (세부 형식은 공식 최종 고시 확인 필요)

### 섹션 구성 (HSK 2.0 기준, 3.0 전환 시 일부 조정 예상)

| 섹션 | 문항 수 | 시간 |
|---|---|---|
| 듣기 | 30문항 | ~30분 |
| 읽기 | 30문항 | ~35분 |
| 쓰기 | 10문항 | ~20분 |
| 답안 작성/전환 | — | ~5분 |

### 문제 유형

**듣기**
- 1부: 대화 — 맞는 문장 판단
- 2부: 짧은 대화 — 객관식
- 3부: 긴 대화 + 단락 독백 — 객관식

**읽기**
- 1부: 빈칸 채우기 (문장 내 어휘)
- 2부: 문장 배열 (순서 맞추기) — 단락 구성
- 3부: 단락 독해 — 객관식

**쓰기**
- 1부: 어순 배열 — 5문항
- 2부: 사진·제시 단어 → 문장 작성 — 5문항

※ HSK 3.0 4급은 **번역 기능** 정식 도입. 구두·서면 번역 과제 추가 가능성 — 공식 시행 세부안 확인 필수.

- 한국 공공기관·대기업 중국어 특기자 가산점.
- 중국 관광가이드 자격증 응시 기초선.

## 7. 학습 로드맵 예시

1. **1~4주**: 3급 취약점 복습, 把/被자문 재정비
2. **5~24주**: 4급 교재 (『HSK Standard Course 4 상·하』 등) 전 과
3. **25~36주**: 어휘 3,245 누적 (3급 대비 1,000 신규 + 2급 이하 복습), 문법 286 패턴 체화
4. **37~44주**: 신문 기사 독해 훈련 (인민일보 海外版·新华网 초급 기사), 중국 드라마·뉴스 듣기
5. **45~48주**: 공식 샘플 + 기출 10회분, 쓰기 모범답안 암기, 번역 기초 연습
6. **시험 직전 2주**: 실전 타이머 모의고사, 약점 섹션 집중
