# HSK 3.0 5급 심층 가이드

> 한어수평고시 신표준(HSK 3.0) 중등 단계 2번째 급수. 중국 학부 유학 주요 기준선.

## 1. HSK 3.0 개요

《国际中文教育中文水平等级标准》(GF0025-2021) 기반. 2021-07-01 공표. **2026-01-31 글로벌 시범 시행 개시**, **2026-07 전면 시행 예정**.

5급은 **중등(4~6급) 중간** 단계. 번역 기능 본격 도입.

상세는 [1급 문서](./1.md) 참조.

## 2. 5급 능력 정의

공식 **5급 능력 기준**:

- 중국어 신문·잡지 기사, 전문 분야 입문 수준 자료 독해
- 중국어 영화·드라마 감상 가능
- 비교적 완전한 연설·발표 수행
- 학술·업무 문서 기초 작성
- 구두·서면 번역 (중↔외) 수행 가능
- 사회·경제·문화 일반 주제 토론 참여

CEFR 대략 B2 수준.

## 3. 학습 범위 (공식 정량)

| 항목 | HSK 3.0 5급 | (참고) HSK 2.0 5급 |
|---|---|---|
| 음절 | 908개 (누적) | — |
| 한자 (인식) | 1,500자 (누적) | 1,685자 |
| 한자 (쓰기) | ~1,200자 (누적) | — |
| 어휘 | 4,316단어 (누적) | 2,500단어 |
| 문법 항목 | 357개 (누적) | 약 180개 |

### 4급 대비 핵심 추가
- **문법 심화**:
  - 문어체(书面语) 표현: 之/其/所/者/乃/而 등 고문 잔재
  - 고급 접속사: 既...又..., 一方面...另一方面..., 不仅...反而..., 一来...二来...
  - 관용 구문: 「就...而言」, 「从...来说」, 「基于...」, 「鉴于...」, 「不得不」, 「免不了」, 「未必」, 「毕竟」
  - 허사 정밀 구분: 又/再/还, 却/但/可, 就/才
  - 사자성어 본격 활용 (약 150~200개)
  - 수동·피동 변형 (遭/受/挨)
- **어휘 주제**: 정치·경제·법률 기초, 과학·기술, 환경·생태, 역사·철학, 매체·광고, 심리·사회
- **번역**: 외↔중 양방향 구두 통역, 서면 번역 (200자 내외 단문)
- **작문**: 의견문·논설문 기초 (400~500자)

### 누적 학습 시간
업계 추정 **1,800~2,500시간**.

## 4. 시험 구성

### 개요
- **문항 수**: 약 80문항
- **총 시간**: 약 125분
- **평가 영역**: 듣기 + 읽기 + 쓰기 + (번역·말하기 일부)

### 섹션 구성 (HSK 3.0 기준, 일부 항목은 공식 최종 고시 재확인 권장)

| 섹션 | 문항 수 | 시간 |
|---|---|---|
| 듣기 | 30~40문항 | ~30분 |
| 읽기 | 30문항 | ~45분 |
| 쓰기 (작문 포함) | 10~20문항 | ~40분 |
| 번역 (신규) | 소량 | 시험지 통합 |
| 답안 작성/전환 | — | ~10분 |

### 문제 유형

**듣기**
- 대화·단락 독백·뉴스 발췌 — 객관식
- 강의·토론 발췌 — 개요·세부 이해

**읽기**
- 빈칸 채우기 (어휘·문법)
- 단락 독해 (다양한 장르: 기사·수필·설명문)
- 장문 독해 — 여러 문단

**쓰기**
- 요약 쓰기 (제시 단어 활용 단락 작성)
- 사진·주제 → 단문 작성 (200~300자)
- 의견문 (400~500자)

**번역**
- 단문 서면 번역 (중↔외)
- 구두 번역 기초 (일부 시행)

## 5. 채점·합격 기준

### 배점
총점 **300점** (듣기·읽기·쓰기 각 100점 기준, 번역은 쓰기에 통합 가능성).

### 합격 조건
**총점 180점 / 300점 이상** (60%).

HSK 3.0 전환 후 섹션별 기준점 도입 가능성 — 공식 최종 고시 확인 권장.

### 성적 유효기간
2년.

### 활용

- 중국 석사 과정 지원 기초선
- 한국 대기업 중국 주재원·중국 법인 파견 기준
- 공기업·정부 중국어 특기자 채용 선호선

## 7. 학습 로드맵 예시

1. **1~4주**: 4급 취약점 복습, 사자성어 150개 선행
2. **5~28주**: 5급 교재 (『HSK Standard Course 5 上·下』 등) 전 과
3. **29~40주**: 어휘 4,316 누적, 문법 357 체화, 신문 사설·방송 뉴스 청취
4. **41~52주**: 공식 샘플 + 기출 10회분, 번역·작문 집중, 한국어↔중국어 양방향 훈련
5. **시험 직전 4주**: 실전 타이머 모의고사 주 2회, 약점 집중
