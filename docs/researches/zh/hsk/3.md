# HSK 3.0 3급 심층 가이드

> 한어수평고시 신표준(HSK 3.0) 초등 단계 최상위 급수. 생활·학습 전반 의사소통 가능 수준.

## 1. HSK 3.0 개요

《国际中文教育中文水平等级标准》(GF0025-2021) 기반. 2021-07-01 실시, **2026-07 전면 시행 예정**. 주관: CLEC / CTI.

3단9급 체계 중 **초등 단계 최상위**. 4차원 기준: 음절·한자·어휘·문법.

## 2. 3급 능력 정의

공식 **3급 능력 기준**:

- 일상생활·학습·업무의 친숙한 화제에서 기본적인 의사소통 수행
- 중국 여행·현지 단기 생활 기본 요구 대응
- 간단한 설명·서술·비교·대조 표현
- 짧은 단락의 의견·감상 작성
- 간단한 안내·공지·메시지 이해 및 작성

CEFR 대략 A2 ~ B1 초반 수준. **초등 단계 완성**.

## 3. 학습 범위 (공식 정량)

| 항목 | HSK 3.0 3급 | (참고) HSK 2.0 3급 |
|---|---|---|
| 음절 | 608개 (누적) | — |
| 한자 (인식) | 900자 (누적) | 617자 |
| 한자 (쓰기) | ~600자 (누적) | — |
| 어휘 | 2,245단어 (누적) | 600단어 |
| 문법 항목 | 210개 (누적) | 약 70개 |

### 2급 대비 핵심 추가
- **문법 심화**:
  - 결과보어 (看见, 听懂, 做完, 学会)
  - 방향보어 (进来, 出去, 上来, 回去 등) + 단순·복합 방향보어
  - 가능보어 (看得懂 / 看不懂)
  - 정도보어 (说得很好)
  - 「把」자문 기초
  - 「被」자문 기초 (수동)
  - 존현문 (존재·출현·소실)
  - 「一边...一边...」「一...就...」 등 복문 접속
  - 「虽然...但是...」「因为...所以...」「如果...就...」 등 복합 구문
  - 강조 구문 「是...的」
- **어휘 주제**: 학교·직장 생활, 취미·운동, 여행·문화 기초, 감정·성격 세분화
- **화용**: 간단한 부탁·거절·제안·사과, 의견 표명

### 누적 학습 시간
업계 추정 **600~800시간** (제로 스타트 누적).

## 4. 시험 구성

### 개요
- **문항 수**: 약 70문항 (HSK 2.0 80문항에서 감소)
- **총 시간**: 약 83분
- **평가 영역**: 듣기 + 읽기 + 쓰기

### 섹션 구성

| 섹션 | 문항 수 | 시간 |
|---|---|---|
| 듣기 | 30문항 | ~30분 |
| 읽기 | 30문항 | ~30분 |
| 쓰기 | 10문항 | ~15분 |
| 답안 작성/전환 | — | ~8분 |

### 문제 유형

**듣기**
- 1부: 대화 — 사진 선택
- 2부: 대화 — 맞는 문장 판단 (✓/✗)
- 3부: 짧은 대화 — 객관식
- 4부: 긴 대화 / 짧은 단락 — 객관식

**읽기**
- 1부: 문장 매칭
- 2부: 빈칸 채우기 (어휘·문법)
- 3부: 단락 독해 — 객관식

**쓰기**
- 1부: 어순 배열 — 5문항
- 2부: 한자 쓰기 (병음 제공) — 5문항

## 5. 채점·합격 기준

### 배점

| 섹션 | 배점 |
|---|---|
| 듣기 | 100점 |
| 읽기 | 100점 |
| 쓰기 | 100점 |
| **총점** | **300점** |

### 합격 조건
**총점 180점 / 300점 이상** (60%).

섹션별 최소 기준 공식 미규정. (HSK 2.0 체계에서는 섹션 하한 없음 — 총점만 충족하면 합격.)

### 성적 유효기간
2년.

## 6. 한국 응시 정보 (2026 기준)

### 주관·접수
- HSK 한국사무국 (hsk.or.kr)
- HSK시험센터 (hsk-korea.co.kr)

### 시험 유형
- HSK IBT / HSK PBT (IBT 확대 추세)

### 2026 응시료
| 형식 | 3급 |
|---|---|
| IBT | 70,000원 |
| PBT | 60,000원 |

### 시험 시간 (통상)
오후 13:30 개시.

### HSK 3.0 전면 시행
**2026-07** 예정. 3급은 초등 완성선으로 전환 영향 큼 — 어휘 600 → 2,245로 대폭 증가. 시험 응시 시점별 체계 확인 필수.

### 중국 유학 활용
- HSK 3급: 중국 어학연수 입학 기준선으로 일부 기관 요구 (3.0 기준은 기존 4급 수준에 근접).
- 중국계 기업 한국 법인 서류전형 기초 인증.

## 7. 학습 로드맵 예시

1. **1~4주**: 2급 취약점 복습, 보어 체계 선행 학습
2. **5~20주**: 3급 교재 (『HSK Standard Course 3』 등) 전 과
3. **21~32주**: 어휘 2,245 누적, 문법 210 패턴 체화, 단락 독해 훈련
4. **33~36주**: 공식 샘플 + 기출 8회분 이상, 쓰기 시간 단축·듣기 집중

## 9. 신뢰도·한계

- **고신뢰**: 3단9급 체계, 합격 총점, 섹션 구조, 한국 시행기관.
- **중신뢰**: 섹션별 문항/시간, 한국 응시료.
- **저신뢰**: 4차원 정량 수치 — 특히 문법 항목 수는 소스 간 편차. 공식 대강(大纲) 기반 인용.
- **미확정**: HSK 3.0 전면 시행 후 시험지 형식 세부 변경 여부. 섹션 기준점 도입 여부.
