# CILS A1 심층 가이드

> Certificazione di Italiano come Lingua Straniera (CILS) 최하위 등급. 이탈리아어 입문자 대상.

## 1. CILS 개요

### 주관
**Università per Stranieri di Siena** (시에나 외국인대학, UNISTRASI) — 이탈리아 교육부 인정 공식 인증 기관. 이탈리아 외교부(Ministero degli Affari Esteri) 인정 4개 공식 이탈리아어 인증 중 하나.

### 4대 공인 이탈리아어 인증
1. **CILS** — Università per Stranieri di Siena
2. **CELI** — Università per Stranieri di Perugia
3. **IT / ele.IT** — Università Roma Tre
4. **PLIDA** — Società Dante Alighieri

CILS는 이탈리아 국내·국제적으로 가장 널리 인정받는 인증 중 하나.

### CILS 레벨 체계
- 일반 6단계 (CEFR): **A1·A2·B1·B2·C1·C2**
- 특수 버전:
  - **CILS A2 Integrazione** (장기 체류허가 목적)
  - **CILS B1 Cittadinanza** (이탈리아 국적 신청)
  - **CILS B1 Adolescenti** (청소년용)
  - **CILS DIT-C2** (이탈리아어 교원 자격)
  - **CILS C1 per professioni mediche** (의료 전문직)

### 학위 특성
- **유효기간 무기한** (평생)
- 이탈리아 외교부·대학 공식 인정
- ALTE 회원 인증

## 2. A1 능력 정의

공식 **A1 능력 기준** (CEFR A1):

- 일상 극히 친숙한 표현·기본 문장 이해·사용
- 자기·타인 소개, 거주지·아는 사람·소유물 등 개인 정보 질의응답
- 상대가 천천히·명확히 말하고 도움 주면 간단 소통 가능

## 3. 학습 범위

### 문법 핵심
- 명사 성·수 (maschile/femminile, singolare/plurale)
- 정관사·부정관사: il/lo/la/i/gli/le, un/uno/una
- 주격 대명사: io/tu/lui/lei/noi/voi/loro
- 동사 essere / avere 현재
- 규칙 동사 3군(-are/-ere/-ire) 현재형
- 주요 불규칙 동사 현재: andare, venire, fare, dare, stare, sapere, potere, volere, dovere
- 재귀동사 기초 (chiamarsi, svegliarsi)
- 부정 non + 동사
- 의문사: chi, che, cosa, dove, quando, come, perché, quanto
- 소유형용사: mio/mia/miei/mie, tuo, suo, nostro, vostro, loro
- 지시사: questo/quello
- 기초 전치사: a, di, da, in, su, per, con, tra/fra
- 전치관사 (Preposizioni articolate): al, del, dal, nel, sul
- 숫자 1~1000, 시간, 날짜

### 어휘 주제
인사·소개, 숫자·날짜·요일·월·시간, 가족, 국적, 직업, 색깔, 음식·음료, 신체, 옷, 집·가구, 교통, 날씨, 일상 동작

### 누적 학습 시간
CEFR 권장 **약 60~100 수업시간** (제로 스타트).

## 4. 시험 구성

### 4개 섹션 (Prove)

| Prova | 내용 | 시간 |
|---|---|---|
| 1. Ascolto (청해) | 2~3 과제 | 약 20분 |
| 2. Comprensione della lettura (독해) | 2~3 과제 | 약 30분 |
| 3. Produzione scritta (작문) | 2 과제 | 약 40분 |
| 4. Produzione orale (구술) | 2~3 과제 | 약 10분 (+ 준비) |

**총 시험 시간**: 약 1시간 40분 (구술 제외 필기) + 구술.

※ A1·A2는 **4개 섹션** (B1~C2는 5개 섹션 — Analisi delle strutture 추가).

### 문제 유형

**Ascolto**: 짧은 대화·공지·메시지 (2회 청취)

**Lettura**: 짧은 텍스트·공지·광고·양식

**Scritto**:
- 양식 채우기 (개인 정보)
- 짧은 메시지·엽서 (30~40단어)

**Orale**:
- 자기소개
- 간단한 질문 답변
- 역할극·상황 대응

## 5. 채점·합격 기준

### 배점
- 각 섹션 고유 점수 (A1은 총점 100점, 섹션별 배점 상이)
- A1 특수: 각 섹션 **11/20 이상**이 통상 합격선 (세부 채점표는 공식 확인)

### 합격 조건
**모든 섹션 개별 합격 필요**. 미달 섹션이 있으면 **Credito(크레딧)** 발급 — 12~18개월 이내 미달 섹션 **재응시 가능**.

### 유효기간
학위 무기한.

## 7. 학습 로드맵

1. **1~4주**: 알파벳·발음·기본 표현 (ciao, buongiorno, come stai?)
2. **5~12주**: A1 교재 (『Nuovo Espresso 1』, 『Nuovissimo Progetto Italiano 1』 1~5과)
3. **13~16주**: 공식 모델 시험지 (UNISTRASI 제공) 4~5회분
4. **17~18주**: 구술 모의 연습
