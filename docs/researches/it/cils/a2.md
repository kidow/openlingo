# CILS A2 심층 가이드

> CILS 초급 상위. 일반 버전 + **Integrazione** (장기 체류허가용) 변형 존재.

## 1. 개요

주관: **Università per Stranieri di Siena**. CEFR A2. 학위 무기한. 상세 체계는 [A1 문서](./a1.md) 참조.

### A2 버전 구분
- **CILS A2**: 일반 학습자용
- **CILS A2 Integrazione**: 이탈리아 장기 체류허가(permesso di soggiorno UE per soggiornanti di lungo periodo) 발급 목적 — 이주민 대상 ([a2-integrazione.md](./a2-integrazione.md) 참조)

두 버전 **시험 구조 동일**, 주제·맥락만 약간 조정.

## 2. A2 능력 정의

공식 **A2 능력 기준** (CEFR A2):

- 일상 경험 영역(가족·쇼핑·근교·직장) 빈번 표현 이해
- 친숙 일상 주제 간단·직접 정보 교환
- 과거·현재·계획된 미래 활동 간단 서술

## 3. 학습 범위

### 문법 핵심 (A1 위에 추가)
- **Passato prossimo** (근과거) — essere/avere + participio passato
- **Imperfetto** 기초
- **Futuro semplice** (단순미래)
- 직접·간접목적격 대명사: mi/ti/lo/la/ci/vi/li/le, gli/le/loro
- 결합 대명사 (Pronomi combinati) 기초
- 재귀동사 심화
- 비교급·최상급: più/meno... di, il/la più...
- 조건법 현재 (Condizionale presente) 기초: vorrei, mi piacerebbe
- 명령법 (Imperativo) 긍정·부정 (tu, Lei)
- 관계대명사 che, cui 기초
- 부정 확장: non...mai, non...niente, non...nessuno, non...più
- 전치사 심화 (Verbi + preposizioni)

### 어휘 주제
A1 확장 + 쇼핑·식당, 여행·호텔, 건강·병원, 취미·여가, 감정·성격, 교육·학업, 일상 경험 서술

### 누적 학습 시간
**약 180~200 수업시간**.

## 4. 시험 구성

### 4개 섹션 (B1 이상과 달리 Analisi delle strutture 없음)

| Prova | 시간 |
|---|---|
| 1. Ascolto | 약 30분 |
| 2. Comprensione della lettura | 약 40분 |
| 3. Produzione scritta | 약 50분 |
| 4. Produzione orale | 약 10분 |

**총**: 약 2시간 필기 + 구술.

### 문제 유형

**Ascolto**: 대화·공지 (2회 청취)

**Lettura**: 광고·공지·짧은 기사·개인 서신

**Scritto**: 
- 비공식 메시지 (엽서·이메일, 50~70단어)
- 양식 작성

**Orale**:
- 자기소개
- 과거 경험 서술
- 친숙 주제 답변
- 역할극

## 8. 학습 로드맵

1. **1~4주**: A1 취약점, passato prossimo·imperfetto 선행
2. **5~16주**: A2 교재 (『Nuovo Espresso 2』, 『Nuovissimo Progetto Italiano 1』 6~12과)
3. **17~22주**: 시제 체계 (presente/passato prossimo/imperfetto) 체화
4. **23~26주**: 공식 모델 4~5회분
