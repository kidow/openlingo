# CILS B1 Cittadinanza 심층 가이드

> **이탈리아 국적 신청 필수 언어 인증**. 2018년 법령 개정으로 이탈리아 시민권 취득 시 의무화.

## 1. 개요

### 대상
- 이탈리아 국적 취득 희망자 (특히 이탈리아인과 결혼한 외국인 배우자, 장기 거주 외국인)
- 이탈리아 내무부(Ministero dell'Interno) 법적 요건 충족 목적

### 근거 법령
- **Legge 1 dicembre 2018, n. 132** — 2018-12-04 시행
- 이탈리아 시민권 신청 시 **B1 이상** 언어 증명 필수화 (이전 A2 수준에서 상향)

### 주관
**Università per Stranieri di Siena**. 일반 CILS B1과 **공식 인증 동등**. 법령이 지정한 4개 공식 이탈리아어 인증 중 하나:
- CILS B1 Cittadinanza (Siena)
- CELI 3 (Perugia)
- IT Roma Tre
- PLIDA (Dante Alighieri)

### 일반 B1과 차이
- **간소화된 시험 구조** — Analisi delle strutture **제외** (4 섹션만 응시)
- 시험 시간 단축
- 배점 체계 단순화
- 주제·맥락 이탈리아 시민 생활·문화 특화

## 2. 능력 정의

일반 B1과 동일 (CEFR B1):

- 업무·학교·여가 등 친숙 주제 표준 언어 요점 이해
- 이탈리아 국내 대부분 상황 대처
- 친숙·개인 관심 주제 연결된 텍스트 산출
- 경험·사건·희망·계획 서술, 의견·이유 제시

Cittadinanza 맥락: 이탈리아 시민 생활, 공공 행정, 역사·문화 기초, 시민 권리·의무.

## 3. 학습 범위

일반 B1과 동일 문법·어휘 범위. 어휘 주제 특화:
- 이탈리아 헌법·공화국 구조
- 역사 기초 (통일·세계대전·공화국 수립)
- 지역·행정 구분
- 시민 권리·의무
- 공공 서비스 (SSN·INPS·Comune)
- 가족·관계 (결혼·자녀·교육)
- 이탈리아 문화·전통·축제
- 시사 기본 이해

### 학습 시간
일반 B1과 동일 — 약 **350~400시간**.

## 4. 시험 구성 (간소화 버전)

### 4개 섹션 — Analisi delle strutture **제외**

| Prova | 시간 | 배점 |
|---|---|---|
| 1. Ascolto | 30분 | 12점 |
| 2. Lettura e riflessione grammaticale | 40분 | 12점 |
| 휴식 | 15분 | — |
| 3. Produzione scritta | 40분 | 12점 |
| 4. Produzione orale | 10분 | 12점 |

**총**: **2시간 5분** (필기 총 2시간) + 10분 구술.

### 문제 유형

**Ascolto**: 대화·공지·인터뷰·시민 생활 상황

**Lettura e riflessione grammaticale**: 
- 독해 지문 + 문법 변환 결합
- 일반 B1의 Lettura + Analisi 간소화 통합

**Scritto**:
- 공식·비공식 텍스트 1~2개
- 약 100~120단어 분량

**Orale**:
- 자기소개 / 이탈리아 거주 경험 / 시민 생활 주제 대화

## 5. 채점·합격 기준

### 배점
- 각 섹션 **12점** × 4 = **총 48점**

### 합격 조건
- **각 섹션 최소 7/12점 이상**
- **총점 28/48점 이상**

### Credito 체계
일반 CILS와 동일 — 미달 섹션만 12~18개월 이내 재응시.

### 유효기간
무기한. 이탈리아 내무부 시민권 심사 공식 증명.

## 6. 한국 응시 정보 (2026)

### 한국 내 특이사항
주 대상이 이탈리아 거주 외국인 — 한국 내 응시 수요 제한적. 이탈리아 현지 응시가 일반적. 한국 응시 시 주한 이탈리아문화원 직접 문의.

### 2026 시험 일정
CILS 공식 일정과 동일. [A1 문서 시험 일정 표](./a1.md#6-한국-응시-정보-2026-기준) 참조. Cittadinanza는 **전 회차 개설**.

### 응시료
이탈리아 본토 기준 약 €100~130 (일반 B1보다 저렴).

## 7. 활용

### 필수 활용
- **이탈리아 시민권 신청** (marriage-based, residence-based 모두)
- 2018년 12월 4일 이후 시민권 신청자 **절대 필수 요건**

### 대체 가능 인증
CILS B1 Cittadinanza 외에도 다음 중 하나 제출 가능:
- CELI 3 Impatto (Perugia)
- IT livello B1 (Roma Tre)
- PLIDA B1 (Dante Alighieri)

## 8. 학습 로드맵

1. **1~4주**: 기존 B1 수준 점검
2. **5~20주**: Cittadinanza 특화 교재 (『Pronti per la Cittadinanza』, 『CILS B1 Cittadinanza - guida』)
3. **21~24주**: 이탈리아 시민 생활·공공 행정 어휘 집중
4. **25~28주**: 공식 B1 Cittadinanza 모델 시험 4~6회분

### 권장 보조 자료
- UNISTRASI 공식 B1 Cittadinanza 모델
- RAI Scuola 시민 교육 프로그램
- 『Costituzione italiana』 (이탈리아 헌법 발췌)
