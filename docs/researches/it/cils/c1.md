# CILS C1 심층 가이드

> CILS 고급. 숙련 사용자 하위. 이탈리아 대학원·전문 분야 기준.

## 1. 개요

주관: **Università per Stranieri di Siena**. CEFR C1. 학위 무기한.

### 특수 버전
- **CILS C1 Standard**: 일반 고급
- **CILS C1 per professioni mediche**: 의료 전문직 대상 특화

### 활용
- **이탈리아 대학원 석·박사 지원** 언어 요건
- **이탈리아 의료 전문의 자격** 언어 증명 (C1 medica)
- 이탈리아 전문 번역·통역 인증
- 이탈리아 교원 자격 기초

## 2. C1 능력 정의

공식 **C1 능력 기준** (CEFR C1):

- 광범위·요구도 높은 장문 텍스트 암시적 의미까지 이해
- 뚜렷한 단어 검색 없이 유창·자발적 표현
- 사회·학술·전문 목적 언어 유연·효과적 사용
- 복잡 주제 명확·잘 구조화된·상세한 텍스트 산출 — 연결사·결속 장치 숙련 사용

## 3. 학습 범위

### 문법·언어 운용 핵심
- 전 문법 체계 숙달 + 미묘한 뉘앙스
- 문어체·격식체 vs 구어체·비격식체 정밀 구분
- 수사법 (metafora, metonimia, ironia, eufemismo)
- 고급 관용 표현·속담·Collocazioni
- 담화 구조·응집성·일관성 장치 숙련
- 다양한 등록: accademico, giuridico, economico, letterario, giornalistico
- Passato remoto 능동 사용
- 고급 Nominalizzazione
- Congiuntivo 전 시제 완전 구사
- 지역 변이 이해 (토스카나·롬바르디아·나폴리·시칠리아 일부)

### 어휘 주제
추상 사상·철학, 사회학·심리학, 경제·금융, 법률·행정, 과학·의학 기초, 문학·예술 비평, 역사·정치, 국제 관계, 이탈리아 현대 사회 심화

### 누적 학습 시간
**약 800~1,000 수업시간**.

## 4. 시험 구성

### 5개 섹션

| Prova | 시간 | 배점 |
|---|---|---|
| 1. Ascolto | 약 30분 | 20점 |
| 2. Comprensione della lettura | 약 80분 | 20점 |
| 3. Analisi delle strutture di comunicazione | 약 70분 | 20점 |
| 4. Produzione scritta | 약 80분 | 20점 |
| 5. Produzione orale | 약 15분 | 20점 |

**총**: 약 **5시간**.

### 문제 유형

**Ascolto**: 라디오·강연·인터뷰·토론 (장시간, 1~2회 청취)

**Lettura**: 장문 기사·문학·학술 발췌·논평

**Analisi**: 고급 문법·어휘·담화·텍스트 구성

**Scritto**: 2개 과제
- 공식 문서·보고서·분석문 (200~250단어)
- 논설·에세이·평론 (250~300단어)

**Orale**: 심화 발표·토론·자료 해석

## 5. 채점·합격 기준

- 각 섹션 20점 × 5 = 총 100점
- 각 섹션 **11/20 이상**
- Credito 체계

## 6. 한국 응시 정보 (2026)

### 시험장
주한 이탈리아문화원 문의.

### 2026 시험 일정
연 6회. [A1 문서 시험 일정 표](./a1.md#6-한국-응시-정보-2026-기준) 참조.

### 응시료
이탈리아 본토 약 €180~220.

### 주요 활용
- **이탈리아 대학원(Laurea magistrale·Dottorato) 지원** 일반 요건
- **이탈리아 의료 전문의 자격** (C1 medica 버전 — 의료 분야 언어 요건)
- **법무·경제·공학 전문직** 언어 인증
- 이탈리아 고등학교 교원 자격 (상위 단계)
- 이탈리아 연구직·학술직 지원
- 한국 대학 이탈리아어 전공 교원 임용
- **Dante Alighieri 국제 통번역** 대학원 지원
- MAECI 장학금 상위 지원

## 7. 학습 로드맵

1. **1~8주**: B2 취약점, 학술·저널리즘 등록 학습
2. **9~40주**: C1 교재 (『Magari C1』, 『Nuovo Contatto C1』, 『Pronti per il CILS C1』)
3. **41~52주**: 학술 논문·Corriere della Sera 문화면·문학 원전 정독, 라디오 프로그램 청취
4. **53~64주**: 공식 모델 8~10회분, 논설 에세이 구조(tesi-antitesi-sintesi) 훈련
5. 시험 직전 6주: Orale 모의 주 2회, 작문 첨삭

### 권장 보조 자료
- Corriere della Sera, La Repubblica, Il Sole 24 Ore 사설·문화면
- RAI Radio 3 『Tutta la città ne parla』, 『Farenheit』
- 문학: Italo Calvino, Primo Levi, Elena Ferrante, Alessandro Baricco, Roberto Saviano
- 학술지: Il Mulino, Nuova Antologia, Paragone
