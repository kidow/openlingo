# CILS B2 심층 가이드

> CILS 중·상급. **이탈리아 대학 학부·대학원 입학 기준선**. 이탈리아 대학 유학 주요 요건.

## 1. 개요

주관: **Università per Stranieri di Siena**. CEFR B2. 학위 무기한.

### B2 특수 활용
- **이탈리아 대학 학부·대학원 입학 언어 요건** — 대부분 대학 B2 요구
- 이탈리아 외교부 공식 학위 인정 — 대학 입학 시 언어 테스트 면제
- **이탈리아 정부 장학금(MAECI)** 지원 기초선

## 2. B2 능력 정의

공식 **B2 능력 기준** (CEFR B2):

- 구체·추상 주제 복잡 텍스트 주요 요지 이해 (전문 분야 기술 논의 포함)
- 원어민과 자연스러운 유창성·자발성으로 상호작용
- 다양한 주제로 명확·상세한 텍스트 산출
- 시사 문제 관점 설명, 선택 장단점 제시

## 3. 학습 범위

### 문법 핵심 (B1 위에 추가)
- **Congiuntivo imperfetto** / **trapassato** 본격
- 조건문 전 체계 (Periodo ipotetico 1·2·3종)
- 가접화법 완전 숙달 (시제 일치)
- Passato remoto 능동 사용 (문어체)
- 분사 구문 (Participio presente/passato)
- Gerundio 구문 확장
- 관용 표현·Collocazioni
- 담화 표지: tuttavia, nondimeno, pertanto, peraltro, difatti, d'altronde
- Nominalizzazione (명사화)
- 전치사 심화·Verbi pronominali (cavarsela, prendersela, farcela)
- Congiuntivo vs Indicativo 정밀 선택

### 어휘 주제
사회·정치·경제 일반, 환경·생태, 기술·혁신, 매체·저널리즘, 교육 제도, 문화 비평, 국제 관계, 이탈리아 현대 사회

### 누적 학습 시간
**약 500~600 수업시간**.

## 4. 시험 구성

### 5개 섹션

| Prova | 시간 | 배점 |
|---|---|---|
| 1. Ascolto | 약 30분 | 20점 |
| 2. Comprensione della lettura | 약 70분 | 20점 |
| 3. Analisi delle strutture di comunicazione | 약 70분 | 20점 |
| 4. Produzione scritta | 약 70분 | 20점 |
| 5. Produzione orale | 약 10분 | 20점 |

**총**: 약 **3시간 40분** + 10분 구술.

### 문제 유형

**Ascolto**: 대화·인터뷰·뉴스·강연 (1~2회 청취)

**Lettura**: 기사·사설·문학 발췌 (다양 장르·장문)

**Analisi**: 문법·어휘 변환·빈칸·오류 찾기 (복잡 구조)

**Scritto**: 2개 과제
- 공식 이메일·서신·보고서 (150~180단어)
- 의견문·논설·기사 (180~220단어)

**Orale**: 주제 발표·심화 대화·사진 기반 토론

## 5. 채점·합격 기준

- 각 섹션 20점 × 5 = 총 100점
- 각 섹션 **11/20 이상**
- Credito 체계 (12~18개월 내 재응시)

## 7. 학습 로드맵

1. **1~4주**: B1 취약점 복습, Congiuntivo 전 시제 선행
2. **5~28주**: B2 교재 (『Nuovissimo Progetto Italiano 2』 7~12과, 『Nuovo Espresso 4』, 『Pronti per il CILS B2』, 『Magari B2』)
3. **29~40주**: 복합 문법·담화 표지 체화, Corriere della Sera·La Repubblica 사설 정독
4. **41~48주**: 공식 모델 10회분, Scritto 2개 과제 구조 훈련
5. 시험 직전 4주: Orale 모의 연습 주 2회
