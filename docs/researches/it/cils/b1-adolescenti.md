# CILS B1 Adolescenti 심층 가이드

> 13~18세 청소년 대상 CILS B1. 주제·맥락 청소년화. 일반 B1과 학위 가치 동등.

## 1. 개요

### 대상
- **13~18세** 청소년
- 이탈리아어 중급 진입 청소년
- 이탈리아 고등학교 교환학생·유학 준비
- 이탈리아 국제학교 학생

### 주관
**Università per Stranieri di Siena**. 일반 B1 및 B1 Cittadinanza와 **학위 가치 동등**.

### 일반 B1과 차이
- 시험 구조·시간·배점·합격 기준 **100% 동일**
- **주제·사진·예시만 청소년 생활 세계**로 조정
- 일반 B1(Standard) 구조 따름 — 5 섹션 (Analisi 포함)

## 2. 능력 정의

일반 B1과 동일 (CEFR B1). 청소년 맥락:
- 학교 생활·수업·시험·진로 탐색
- 또래 관계·우정·갈등
- 가족 관계 (부모·형제)
- SNS·인터넷·디지털 문화
- 스포츠·음악·문화
- 청소년 건강·감정·정체성
- 여행·교환학생·문화 체험
- 청소년 시사·환경·사회 참여

## 3. 학습 범위

일반 B1과 동일 문법 범위:
- Congiuntivo presente / passato
- Condizionale presente / passato
- Passato remoto (인식)
- Trapassato prossimo
- 직·간접화법
- 수동태
- 조건문 1종·2종
- 결합 대명사 전체

청소년 어휘 주제:
- Scuola, insegnanti, compagni di classe
- Amicizia, primi amori, social media
- Sport, musica, film, videogame
- Futuro, università, professione
- Ambiente, clima, diritti dei giovani
- Viaggio, scambi, festival

### 학습 시간
일반 B1과 동일 — 약 **350~400 수업시간**.

## 4. 시험 구성

일반 B1 Standard와 **동일 5 섹션 구조**.

| Prova | 시간 | 배점 |
|---|---|---|
| 1. Ascolto | 약 30분 | 20점 |
| 2. Comprensione della lettura | 약 40분 | 20점 |
| 3. Analisi delle strutture di comunicazione | 약 60분 | 20점 |
| 4. Produzione scritta | 약 60분 | 20점 |
| 5. Produzione orale | 약 10분 | 20점 |

**총**: 약 2시간 15분.

### 문제 유형 (청소년 맥락)
- Ascolto: 청소년 라디오·팟캐스트·또래 대화·학교 공지
- Lettura: 청소년 잡지 기사·블로그·SNS 포스트·학교 관련 문서
- Analisi: 청소년 텍스트 기반 문법·어휘
- Scritto: 친구 이메일·학교 블로그·청소년 시사 의견문
- Orale: 학교 생활 서술·청소년 상황 역할극·또래 주제 대화

## 5. 채점·합격 기준

일반 B1과 동일:
- 각 섹션 20점 × 5 = 총 100점
- 각 섹션 **11/20 이상**
- Credito 체계 (미달 섹션 재응시 12~18개월)

### 학위
**"CILS B1 Adolescenti"**. 일반 B1과 동등 가치. 무기한 유효.

## 6. 한국 응시 정보 (2026)

### 시험장
주한 이탈리아문화원 문의.

### 2026 시험 일정
CILS 공식 일정과 동일. 청소년 버전 개설 여부 회차별 상이 — 공식 공지 확인 필수.

### 응시료
한국 내 응시 시 별도 안내. 이탈리아 본토 기준 일반 B1과 동일 약 €120~160.

## 7. 활용

- **이탈리아 고등학교 교환학생·유학** 언어 증명
- 이탈리아 국제학교 편입 기초선
- **한국 외고·국제고 이탈리아어 특기자** 대외 스펙
- 한국 대학 특별전형 이탈리아어 가산
- 청소년 이탈리아어 학습 공식 성취 증명
- 대학 입학 준비 단계 (이후 B2·C1로 이동)

## 8. 학습 로드맵

1. **1~4주**: A2 취약점, Congiuntivo presente 선행
2. **5~24주**: 청소년 대상 교재 (『Espresso ragazzi』, 『Amici d'Italia』, 『Pronti per CILS B1 - versione adolescenti』)
3. **25~32주**: 시제·접속법 체계 완성, 청소년 팟캐스트·뉴스 청취
4. **33~36주**: 공식 B1 Adolescenti 모델 시험 4~6회분
5. 시험 직전 2주: Orale 파트너 모의
