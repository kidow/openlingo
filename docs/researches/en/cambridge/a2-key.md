# Cambridge A2 Key (KET) 심층 가이드

> Cambridge English Qualifications 최하위. **A2 Key (KET — Key English Test)**. CEFR A2 대응. 학습자 연령별 버전 존재.

## 1. Cambridge English 개요

### 주관
**Cambridge University Press & Assessment** (구 Cambridge Assessment English / UCLES). 영국 케임브리지 대학 산하 공식 기관.

### Cambridge English Qualifications 체계 (CEFR 대응)
| Cambridge | 약칭 | CEFR |
|---|---|---|
| A1 Movers / A2 Flyers (아동) | — | A1~A2 |
| **A2 Key** | **KET** | **A2** |
| B1 Preliminary | PET | B1 |
| B2 First | FCE | B2 |
| C1 Advanced | CAE | C1 |
| C2 Proficiency | CPE | C2 |

### 공통 특성
- **학위 무기한 유효** (expire 없음)
- 전 4 기술 평가 (Reading/Writing/Listening/Speaking) — FCE·CAE·CPE는 **Use of English 추가**
- IELTS와 **동일 기관 주관** (Cambridge + British Council + IDP)
- ALTE Q-Mark 품질 인증

### A2 Key 버전
- **A2 Key** — 일반 성인
- **A2 Key for Schools** — 학령기 청소년 대상 (주제 학교·청소년 조정, 학위 동등)

## 2. A2 능력 정의

공식 **A2 Key 능력 기준** (CEFR A2):

- 일상 경험 영역(가족·쇼핑·근교·직장·학교) 빈번 표현 이해
- 친숙 일상 주제 간단 직접 정보 교환
- 과거·현재·계획된 미래 활동 간단 서술

## 3. 시험 구성

### 3 paper / 4 기술

| Paper | 내용 | 시간 | 배점 비중 |
|---|---|---|---|
| 1. Reading and Writing | 7 파트, 32문항 | 60분 | 50% |
| 2. Listening | 5 파트, 25문항 | 약 30분 (+6분 전사) | 25% |
| 3. Speaking | 2 파트 (파트너와) | 8~10분 | 25% |

**총**: 약 2시간 + Speaking.

### 문제 유형

**Reading and Writing** (7 파트)
- 파트 1~5: 독해 (광고·메시지·짧은 글·쉬운 텍스트 + 빈칸·객관식)
- 파트 6~7: 쓰기 (짧은 메시지 25단어+ / 이야기 35단어+)

**Listening** (5 파트)
- 짧은 대화·안내·전화 메시지
- 객관식·빈칸

**Speaking** (파트너와 2명씩)
- 파트 1: 자기소개·친숙 주제 (3~4분)
- 파트 2: 사진 묘사·공동 과제 (5~6분)

## 4. 채점·성적

### Cambridge English Scale
- **100~150점 스케일**
- A2 Key 합격 구간: **120~150**

### 판정
| 점수 | 등급 | 수여 증서 |
|---|---|---|
| 140~150 | Pass with Distinction | **A2 Key 증서 + B1 CEFR 인정** |
| 133~139 | Pass with Merit | A2 Key 증서 |
| 120~132 | Pass | A2 Key 증서 |
| 100~119 | A1 수준 | **A1 증서** 별도 수여 |
| <100 | 증서 없음 | — |

※ **고득점 시 상위 레벨(A2→B1) CEFR 인정**. 저득점 시에도 **하위 A1 증서 수여** 가능 — 낭비 없음.

### 유효기간
**무기한**.

### 결과 발표
- 시험 후 **2~3주** (Paper-based) 또는 **7일** (Computer-based)
- Cambridge Candidate Results Online 조회

## 5. 한국 응시 정보 (2026)

### 주관·접수
- **British Council Korea** (britishcouncil.kr)
- Cambridge English 공식 시험장 (영국문화원 협력 기관)

### 응시료
참고치 (2025 기준): **약 110,000~150,000원**.

### 시험 일정
연 수 회 (Paper-based) / CBT 가능. British Council 공식 일정 확인.

### 시험장
서울·부산·대구·광주 British Council 시험장.

## 6. 활용

- **영국 학교·초·중등 유학** 언어 증명 (A2 Key for Schools 특화)
- 영국 단기 비자 일부 — B1 이상 요구가 많으므로 A2 Key는 보조
- **어린이·청소년 영어 학습 공식 성취 증명**
- 한국 외고·국제학교 영어 성취 인증

## 7. 학습 로드맵

1. **1~8주**: 기초 문법·어휘 (『Compact Key for Schools』, 『Complete Key』)
2. **9~16주**: Cambridge 공식 샘플 기출 2~3회분
3. **17~20주**: Speaking 파트너 모의
