# TOEIC Listening & Reading 심층 가이드

> Test of English for International Communication (TOEIC) L&R. 비즈니스·일상 영어 의사소통 평가. 한국 영어 시험 표준 1위.

## 1. 개요

### 주관
- **ETS** (Educational Testing Service, 미국) — 시험 개발·채점
- 한국 시행: **YBM** (한국토익위원회) — 1982년 이후 국내 독점 시행

### 시험 특성
- **L&R 2개 파트** (Listening + Reading)
- 객관식 (4지선다)
- 만점 **990점** (L 495 + R 495)
- 비즈니스·일상 영어 중심
- **합격·불합격 개념 없음** — 점수 자체가 인증
- 성적 **2년 유효**

### TOEIC 계열
- **TOEIC L&R** (본 문서) — 청해·독해
- **TOEIC Speaking** ([toeic-speaking.md](./toeic-speaking.md))
- TOEIC Writing
- TOEIC Bridge (초·중급자용)

## 2. 시험 구성

### 총 200문항·2시간

| 파트 | 내용 | 문항 수 | 시간 |
|---|---|---|---|
| **Listening** | | **100문항** | **45분** |
| Part 1 | 사진 묘사 | 6 | |
| Part 2 | 질의응답 | 25 | |
| Part 3 | 짧은 대화 | 39 (13 대화 × 3문항) | |
| Part 4 | 설명문 | 30 (10 지문 × 3문항) | |
| **Reading** | | **100문항** | **75분** |
| Part 5 | 단문 빈칸 채우기 | 30 | |
| Part 6 | 장문 빈칸 채우기 | 16 (4 지문 × 4문항) | |
| Part 7 | 독해 | 54 (단일 지문 29 + 다중 지문 25) | |

**총**: 200문항 / 120분 (2시간) 순수 시험 + 약 30분 행정 = **2시간 30분 체류**.

### 문제 유형 상세

**Part 1 (사진 묘사)**: 사진 1장 + 4개 진술 청취, 맞는 것 선택

**Part 2 (질의응답)**: 질문·진술 1개 + 답변 3개 청취, 맞는 답변 선택

**Part 3 (짧은 대화)**: 2~3인 대화 청취 + 3문항 객관식 (스크립트·질문 시각 제공)

**Part 4 (설명문)**: 안내방송·뉴스·광고 독백 + 3문항

**Part 5**: 단문 내 빈칸 문법·어휘

**Part 6**: 장문 내 빈칸 (문법·어휘·문장 삽입)

**Part 7**:
- Single Passages: 이메일·기사·광고·공지 등 단일 지문
- Double Passages: 2개 연관 지문
- Triple Passages: 3개 연관 지문

## 3. 채점·성적

### 환산점수 (Scaled Score)
- 실제 정답 수를 IRT(문항반응이론) 기반 환산
- L 495 + R 495 = **총 990**
- 5점 단위 (최저 5점부터)

### 성적별 영어 수준 (참고)

| 점수 | 수준 | CEFR 대략 |
|---|---|---|
| 905~990 | International Professional | C1+ |
| 785~900 | Working Proficiency | B2 |
| 605~780 | Limited Working | B1 |
| 405~600 | Elementary | A2 |
| 255~400 | Basic | A2- |
| 10~250 | Novice | A1 |

### 유효기간
**시험일로부터 2년**. 이후 재응시 필요.

### 성적표
- 온라인 조회: 시험일 **9일 후 화요일 12시**
- 종이 성적표: 시험일 약 2주 후 발송

## 4. 한국 응시 정보 (2026)

### 응시료
**52,500원** (2025~2026 기준).

### 시험 일정
- 월 **2~3회** (주로 일요일 오전 9:30 개시)
- 2026 첫 시험: **2026-01-11 (일)**
- 연 30회 이상 개설 — 한국 영어 시험 중 가장 빈번

### 접수
- exam.toeic.co.kr (YBM 토익)
- 시험 약 2~3주 전 접수 개시
- 결제: 카드·계좌이체

### 시험장
전국 주요 도시·대학·학원 수백 곳. 가장 접근성 높은 영어 시험.

### 2026 정부 지원
- 한국토익위원회 **청년 응시료 지원 사업** (공식 공지)
- 만 19~34세 청년 대상 일부 회차 무료·할인

## 5. 활용

### 한국
- **대기업 입사 서류 전형** 가장 널리 요구 (700~900점 구간)
- **공기업·공공기관** 영어 어학 성적 (대부분 TOEIC 수용)
- 대학 졸업 요건 (주요 대학 600~800점)
- 대학원 지원 보조
- 승진·인사 평가

### 국제
- 일본·대만 등 아시아 일부 기업
- 한국 외 TOEIC 인지도 제한적 — **유학·이민에는 부적합** (TOEFL·IELTS 필요)

## 6. 학습 로드맵

### 초보자 (400점 이하)
1. **1~4주**: 기본 문법 재정비 (시제·관사·품사)
2. **5~12주**: 『해커스 토익 기본서』, 『YBM 토익 스타트』
3. **13~16주**: 파트별 문제 유형 익히기

### 중급 (400~700점)
1. **1~8주**: 『해커스 토익 LC·RC』, 『시나공 토익』
2. **9~16주**: 어휘 암기 (『Voca 33000』, Part 5·6 빈출)
3. **17~20주**: 실전 모의고사 주 2회

### 고급 (700점 이상 → 900+ 목표)
1. **1~8주**: ETS 공식 기출 Reading Collection·Listening Collection
2. **9~16주**: 실전 RC 시간 관리 (75분 100문항)
3. 약점 파트 집중

### 권장 자료
- **공식 ETS 기출**: YBM 공식 『ETS TOEIC RC/LC 1000』 시리즈
- **해커스**·**시나공**·**YBM** 계열 실전서
- **앱**: ETS Toeic Official Speaking/Listening
