# Goethe-Zertifikat B1 심층 가이드

> 중급 입문. **독일 영주권·귀화 언어 요건**. 최초 **모듈 시험**.

## 1. 개요

주관: **Goethe-Institut**. CEFR B1. **telc·ÖSD와 공동 개발** (독일·스위스·오스트리아 3국 공동 인증).

### 특징
- **모듈 시험** 최초 적용 — 듣기·읽기·쓰기·말하기 각 모듈 **독립 응시** 가능
- 각 모듈 개별 합격·불합격 판정, 개별 증서 발급 가능
- 4개 모듈 모두 합격 시 통합 증서(Gesamtzertifikat) 발급
- 성인(16세+) / 청소년(12세+) 2개 버전, 학위 동등

### 활용
- **독일 영주권 신청 언어 요건** (B1 필수)
- **독일 귀화(Einbürgerung) 언어 요건**
- 독일 대학 학부 유학 준비(Studienkolleg) 기준
- 독일 기업 취업 기초 인증

## 2. B1 능력 정의

공식 **B1 능력 기준**:

- 업무·학교·여가 등 친숙 주제 표준 언어 명확 입력 요점 이해
- 독일어권 여행 중 대부분 상황 대처
- 친숙·개인 관심 주제 연결된 텍스트 산출
- 경험·사건·희망·계획 서술, 의견·이유 제시

## 3. 학습 범위

### 문법 핵심 (A2 위에 추가)
- **Konjunktiv II** 본격 — würde + Infinitiv, wäre, hätte, könnte (가정·정중)
- **Passiv** (수동) — werden + Partizip II (현재·과거)
- **Präteritum** 전체 동사 (서면 서술 시제)
- Plusquamperfekt (과거완료)
- Futur I·II (미래)
- 분사 구문 (Partizip I·II 수식)
- 관계대명사 전체 4격 + wo/was
- 종속절 확장: damit, deshalb, obwohl, trotzdem, während, seit, bis, solange
- 접속사 구분: denn vs weil, aber vs sondern, deswegen vs trotzdem
- n-Deklination (약변화 명사)
- Genitiv 본격

### 어휘 주제
사회 이슈, 매체·인터넷, 환경, 과학·기술 기초, 문화·예술, 직장·경력, 관계·감정 심화, 건강·의료, 교육 제도

### 누적 학습 시간
**약 350~650 수업시간**.

## 4. 시험 구성

### 4개 모듈 (독립 응시 가능)

| 모듈 | 시간 |
|---|---|
| Lesen | 65분 |
| Hören | 40분 |
| Schreiben | 60분 |
| Sprechen | 15분 (+ 준비 15분) |

**전 모듈 일괄 응시 시**: 약 **180분** + Sprechen.

### 문제 유형

**Lesen** (5개 파트, 30문항)
- 개인 이메일·블로그
- 기사·설명문
- 광고 매칭
- 의견·댓글
- 공식 안내

**Hören** (4개 파트, 30문항)
- 짧은 공지·뉴스 (1회 청취)
- 대화·인터뷰 (2회 청취)
- 라디오·강의 발췌
- 토론·의견 교환

**Schreiben** (3개 파트)
1. 비공식 이메일·편지 (약 80단어)
2. 포럼·게시판 댓글·의견문 (약 80단어)
3. 공식 이메일·편지 (약 40단어)

**Sprechen** (집단 — 파트너와)
1. Teil 1: 공동 계획 (2~3분)
2. Teil 2: 주제 발표 (3~4분, 준비 후)
3. Teil 3: 상대 발표 후 피드백·질문

## 5. 채점·합격 기준

### 배점
- 각 모듈 **100점** (B1은 모듈당 100점 배점)
- **모듈별 합격**: **60점 / 100점 이상** (60%)

### 합격 기록
- 개별 모듈 합격 시: 해당 모듈 Einzelzertifikat 발급
- 4개 모듈 모두 합격 시: **Goethe-Zertifikat B1 Gesamtzertifikat** (통합 증서)
- 일부 모듈 불합격 시: 해당 모듈 **재응시 가능** (합격 모듈은 유효, 1년 이내 재응시 권장)

### 유효기간
무기한. 영주권·귀화 절차 목적은 보통 별도 제한 없음 (성적 증명으로 활용).

## 6. 한국 응시 정보 (2026)

### 응시료
참고치 (2025 기준): 전 모듈 일괄 **약 330,000~380,000원**, 모듈별 개별 응시 각 **약 100,000~120,000원**.

### 시험 일정
연 10회+. 서울 Goethe-Institut Korea.

## 7. 학습 로드맵

1. **1~4주**: A2 취약점, Konjunktiv II·Passiv 선행
2. **5~24주**: B1 교재 (『Menschen B1』, 『Netzwerk neu B1』, 『Aspekte neu B1+』, 『Fit fürs Goethe-Zertifikat B1』)
3. **25~32주**: 시제·수동 체계 완성, 뉴스·팟캐스트 청취
4. **33~36주**: 공식 모델 6~8회분, Schreiben 3파트 구조 훈련
