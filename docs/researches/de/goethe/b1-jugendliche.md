# Goethe-Zertifikat B1 (Jugendliche) 심층 가이드

> 12~16세 청소년 대상 Goethe B1. 성인 B1과 **동일 시험 구조·배점·합격선**, 주제만 청소년화.

## 1. 개요

### 대상
- **12~16세** 청소년
- 독일어 중급 진입 청소년
- 독일 교환학생·Gymnasium 편입·청소년 독일어 캠프 참가자

### 주관
**Goethe-Institut**. **telc·ÖSD와 공동 개발** (독일·스위스·오스트리아 3국 공동 인증).

### 성인 vs 청소년 버전
| 버전 | 대상 |
|---|---|
| **Goethe-Zertifikat B1** | 성인 16세+ |
| **Goethe-Zertifikat B1 für Jugendliche** | 청소년 12~16세 |

**시험 구조·시간·배점·합격선 동일**. 주제만 청소년 생활 세계로 조정.

**학위 동등**: 청소년 버전 증서도 성인 B1과 같이 **영주권·귀화 언어 요건** 인정 (독일 당국 기준).

### 특징
- **모듈 시험** — 듣기·읽기·쓰기·말하기 각 독립 응시 가능
- 각 모듈 100점 만점·60점 합격
- 모듈별 증서 발급 / 4개 모두 합격 시 통합 증서

### 활용
- **독일 Gymnasium 고학년 편입** 언어 증명
- 독일 교환학생 심화 프로그램
- **독일 영주권·귀화 언어 요건** (미래 활용)
- 독일 학부 유학 사전 준비
- 한국 외고·국제고 독일어 심화 인증
- 대학 특별전형 독일어 특기자

## 2. B1 능력 정의

일반 B1과 동일 (CEFR B1):

- 업무·학교·여가 등 친숙 주제 표준 언어 요점 이해
- 독일어권 여행 대부분 상황 대처
- 친숙·개인 관심 주제 연결된 텍스트 산출
- 경험·사건·희망·계획 서술, 의견·이유 제시

청소년 맥락:
- 학교·수업·시험·진로 탐색 심화
- 또래·우정·갈등·학교폭력
- 가족 관계 심화
- SNS·미디어·게임 중독·디지털 윤리
- 환경·기후변화
- 스포츠·음악·문화
- 청소년 건강·정체성·정치 참여
- 여행·문화 체험·교환학생

## 3. 학습 범위

성인 B1과 동일 문법 범위:
- **Konjunktiv II** 본격 (가정·정중)
- **Passiv** (수동) 현재·과거
- Präteritum 전체 동사
- Plusquamperfekt
- Futur I·II
- 분사 수식
- 관계절 4격 전체
- 종속절 확장 (damit, obwohl, während, seit, bis)
- n-Deklination
- Genitiv 본격

### 학습 시간
**약 350~600 수업시간**.

## 4. 시험 구성

성인 B1과 **동일 4 모듈 구조·시간**.

| 모듈 | 시간 |
|---|---|
| Lesen | 65분 |
| Hören | 40분 |
| Schreiben | 60분 |
| Sprechen | 15분 (+ 준비 15분) |

**전 모듈 일괄 응시**: 약 180분 + Sprechen.

### 문제 유형

**Lesen**: 5개 파트 — 청소년 잡지 기사·학교 공지·SNS 포스트·블로그·청소년 광고

**Hören**: 4개 파트 — 청소년 라디오·팟캐스트·학교 공지·또래 대화·교사 설명

**Schreiben**: 3개 파트
1. 친구·또래 이메일·메시지 (약 80단어)
2. 학교·청소년 포럼 의견문 (약 80단어)
3. 교사·기관 공식 메시지 (약 40단어)

**Sprechen** (집단 — 청소년 파트너):
- Teil 1: 공동 계획 (학교 행사·여행·파티 등)
- Teil 2: 주제 발표 (청소년 시사)
- Teil 3: 상대 발표 피드백·질문

## 5. 채점·합격 기준

- 각 모듈 **100점** × 4
- **모듈별 합격**: **60/100 이상**
- 모듈 독립 응시·재응시·통합 증서 체계 성인 B1과 동일

### 학위
**"Goethe-Zertifikat B1 für Jugendliche"**. 성인 B1과 동등. 무기한.

## 7. 학습 로드맵

1. **1~4주**: A2 Fit in Deutsch 취약점 복습, Konjunktiv II·Passiv 선행
2. **5~24주**: 청소년 대상 B1 교재 (『Prima B1』, 『Beste Freunde B1.1·B1.2』, 『deutsch.com 3』, 『Fit fürs Goethe-Zertifikat B1 Jugendliche』)
3. **25~32주**: 시제·수동 체계 완성, 청소년 뉴스·팟캐스트 청취
4. **33~36주**: 공식 모델 6~8회분, Schreiben 3파트 훈련
5. 시험 직전 4주: Sprechen 파트너 모의 연습
