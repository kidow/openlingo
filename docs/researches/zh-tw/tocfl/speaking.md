# TOCFL 口說測驗 (말하기 시험) 심층 가이드

> 화어문능력시험 말하기 별도 시험. 聽讀測驗과 분리 응시. Band A·B·C 각 레벨별 형식 존재.

## 1. 개요

### 위치
TOCFL 주 시험(聽讀測驗)과 **별도**로 응시. 수험자는 聽讀과 독립적으로 필요에 따라 口說測驗만 응시 가능 (또는 통합 응시).

### 주관
**SC-TOP**. 시험 채점은 훈련된 채점자(trained rater) 2인 이상 교차 평가.

### 레벨 구분
- **Band A 口說測驗**: Level 1·2 (入門·基礎級) 대응
- **Band B 口說測驗**: Level 3·4 (進階·高階級) 대응
- **Band C 口說測驗**: Level 5·6 (流利·精通級) 대응

동일 Band 내 2개 레벨은 **동일 시험**으로 응시 후 성적 구간에 따라 판정.

## 2. 시험 구성

### 기본 형식
- **컴퓨터 녹음** 방식 (CBT)
- 지시·과제가 화면·오디오로 제공
- 수험자는 마이크에 답변 녹음
- 제한 시간 내 응답 완료

### Band별 시간·과제 (공식 대강, 시험장별 편차 가능)

| Band | 총 시간 | 주요 과제 |
|---|---|---|
| Band A (L1·L2) | 약 20~25분 | 따라 읽기, 짧은 질문 답변, 그림 묘사, 간단한 상황 대응 |
| Band B (L3·L4) | 약 25~30분 | 낭독, 질문 답변, 그림·자료 묘사, 의견 표현, 상황 대화 |
| Band C (L5·L6) | 약 30~35분 | 장문 낭독, 심화 질문 답변, 자료 기반 발표, 논증·토론 |

### 공통 과제 유형
1. **낭독 (朗讀)** — 제시 문장·단락 소리 내어 읽기
2. **답변 (回答問題)** — 질문에 답변
3. **묘사 (看圖說話 / 描述)** — 그림·사진·자료 설명
4. **재진술 (重述)** — 청취 내용 요약 재진술 (Band B·C)
5. **의견 표현 (表達意見)** — 주제에 대한 입장 논술
6. **역할 수행 (情境對話)** — 지정 상황 대응 (Band B·C)

## 3. 평가 기준

### 4가지 평가 차원
1. **발음 (語音)** — 성조 정확성, 음절 명확성
2. **어휘·문법 (詞彙文法)** — 사용 어휘 다양성·정확성, 문법 정확성
3. **유창성 (流暢度)** — 자연스러운 속도, 머뭇거림·멈춤 빈도
4. **내용·논리 (內容與邏輯)** — 과제 적합성, 논리 구성, 표현 깊이

### 배점·판정
- 각 과제별 **6급분(六級分) 척도** 또는 TOCFL 전용 척도로 채점
- Band 내 Level 판정:
  - 상위 구간 → 상위 레벨 증서 (예: Band A에서 Level 2)
  - 중위 구간 → 하위 레벨 증서 (예: Level 1)
  - 기준 미달 → 미수여

구체 컷오프 수치는 SC-TOP 공식 기준 대기 — 공식 사이트 확인.

### 증서
- 별도 口說 증서 발급
- 聽讀 증서와 통합 또는 분리 표시 — 센터별 양식 상이
- 유효기간 **2년**

## 4. 성적 발표

- **시험 후 40일** 이후 조회 가능 (온라인 등록 시스템)
- 공식 성적표: **45일 후** 발송
- 聽讀測驗(20일·25일)보다 느림 — 수동 채점 공정 포함

## 5. 한국 응시 정보 (2026 기준)

### 문의
- 駐韓國台北代表部 02-6329-6000
- SC-TOP 사이트

### 응시료
한국 내 회차별 안내. 口說은 聽讀과 별도 응시료 — 대만 본토 참고치 NT$1,500~2,000.

### 시행 형태
- **컴퓨터 기반(CBT)** 필수
- 한국 내 口說 시행 시험장·회차 제한적 — 사전 문의 필수

## 6. 활용

- **대만 대학 교환학생·학부 입학** 일부 학과 口說 요구
- **대만 대학원** 일부 전공 (신문방송·언론·통번역) 口說 필수
- **대만 취업 비자·연구직 지원** 일부 기관 口說 요구
- **華語文教學能力證書** (대만 중국어 교원 자격) 응시 기초
- 통역 대학원 지원 경쟁력

## 7. 학습 로드맵

### 공통
1. 발음·성조 교정 (중국어 音韻 코치 활용)
2. 상용 과제 유형별 스크립트 준비·암기
3. 녹음 후 자가 점검 (발음·속도·멈춤)
4. 원어민 튜터·언어교환 파트너와 실전 대화
5. SC-TOP 공식 모의 口說 시험 문제 반복

### Band별 특수 집중
- **Band A**: 발음·기본 표현 정확성, 친숙 주제 답변 분량 확보
- **Band B**: 논리적 연결, 의견 진술 구조, 자연스러운 속도
- **Band C**: 추상 주제 논증, 다양 등록 조절, 수사 활용
