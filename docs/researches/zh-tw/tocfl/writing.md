# TOCFL 寫作測驗 (쓰기 시험) 심층 가이드

> 화어문능력시험 쓰기 별도 시험. 聽讀測驗과 분리 응시. Band A·B·C 각 레벨별 형식 존재.

## 1. 개요

### 위치
TOCFL 주 시험(聽讀測驗)과 **별도 응시**. 독립적으로 寫作測驗만 응시 가능.

### 주관
**SC-TOP**. 훈련된 채점자 2인 이상 교차 평가.

### 레벨 구분
- **Band A 寫作測驗**: Level 1·2 대응
- **Band B 寫作測驗**: Level 3·4 대응
- **Band C 寫作測驗**: Level 5·6 대응

### 문자 입력
- **번체자** 입력 (주음부호·창힐·행남·한어병음 등 입력법 선택)
- CBT 환경에서 진행 (일부 PBT 운영 병행 가능)

## 2. 시험 구성

### 기본 형식
- **컴퓨터 기반(CBT)** 중심
- 지정 시간 내 주어진 과제 서면 작성
- 분량 제한 있음

### Band별 시간·과제 (공식 대강)

| Band | 총 시간 | 주요 과제 | 분량 |
|---|---|---|---|
| Band A (L1·L2) | 약 40~50분 | 양식 채우기, 짧은 메시지, 개인 서신 | 100~200자 |
| Band B (L3·L4) | 약 60~80분 | 이메일, 짧은 기사, 의견문, 자료 기반 요약 | 300~500자 |
| Band C (L5·L6) | 약 80~100분 | 논설문, 학술 에세이, 보고서, 평론 | 600~1,000자 |

### 공통 과제 유형
1. **실용문 쓰기** — 이메일·편지·공지·안내문 (Band A·B)
2. **서술문** — 경험·사건·장면 묘사 (Band A·B)
3. **의견문** — 주제에 대한 입장·논증 (Band B·C)
4. **통합 과제** — 독해 자료 읽고 요약·의견 작성 (Band C)
5. **학술·전문 쓰기** — 논설·평론·보고 (Band C)

## 3. 평가 기준

### 4가지 평가 차원
1. **과제 수행 (任務完成)** — 주제·목적·분량 달성
2. **언어 정확성 (語言準確性)** — 어휘·문법·한자·부호 정확성
3. **언어 운용 (語言運用)** — 어휘·구문 다양성, 등록 적합성
4. **편집·조직 (組織與連貫)** — 단락 구성, 응집성·일관성

### 배점·판정
- 과제별 6급분(六級分) 또는 TOCFL 전용 척도
- Band 내 Level 판정: 상위 → 상위 레벨, 중위 → 하위 레벨, 미달 → 미수여
- 정확 컷오프는 SC-TOP 공식 고시 확인

### 증서
별도 寫作 증서 발급. 유효기간 **2년**.

## 4. 성적 발표

- 시험 후 **40일** 이후 온라인 조회
- 공식 성적표: **45일 후** 발송

## 5. 한국 응시 정보 (2026 기준)

### 문의
- 駐韓國台北代表部 02-6329-6000
- SC-TOP 사이트

### 응시료
한국 내 회차별 안내. 寫作은 별도 응시료. 대만 본토 참고치 NT$1,500~2,000.

### 시행 형태
- CBT 필수 (번체자 입력법 숙달 전제)
- 한국 내 寫作 시행 시험장 제한적 — 사전 문의

### 번체자 입력 장벽
한국인 수험자는 **입력법 선택**이 추가 관문:
- **주음부호(注音)**: 대만 표준, 학습 필요 (약 2~4주)
- **한어병음(漢語拼音)**: 한국인 친숙, 일부 시스템 지원
- **창힐(倉頡)**: 숙달 어려움, 홍콩·기존 번체 사용자용
- **행남(行列)·대역(大易)** 등: 생소, 비권장

## 6. 활용

- **대만 대학 학부·대학원** 일부 학과 寫作 요구
- **대만 교사 자격·공무원 중국어직** 응시 기초
- 국제 번역 인증 (번체 중국어 방향)
- **華語文教學能力證書** 응시
- 대만 매체·출판·언론 취업
- 한국 내 번역 전문가 번체 중국어 인증

## 7. 학습 로드맵

### 공통
1. **번체자 입력법 선택·숙달** (우선순위)
2. 상용 과제 유형별 모범답안 분석·암기
3. 원고지(400자·600자 기준) 쓰기 훈련
4. 원어민 첨삭 (발표 가능한 수준 답안 확보)
5. SC-TOP 공식 寫作 모의 문제 반복

### Band별 특수 집중
- **Band A**: 기본 문형 정확성, 양식·단문 구조
- **Band B**: 단락 구성, 논리 연결사, 의견 전개 구조
- **Band C**: 논증 구조, 등록 조절, 수사법, 어휘 다양성

### 권장 보조 자료
- SC-TOP 공식 寫作 모의시험
- 대만 고등학교 作文 지도서 (본토 학생용)
- 臺灣華語文學習中心 寫作 수업
- 대만 신문 사설·칼럼 정독 (모델 텍스트)

- **고신뢰**: 寫作 분리 응시, 3 Bands 체계, 4개 평가 차원, 성적 40일 후 발표, 2년 유효, 번체자 입력법 필요.
- **중신뢰**: Band별 시간·분량 기준 (공식 대강).
