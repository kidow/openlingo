# TORFL A2 (ТБУ / Basic) 심층 가이드

> TORFL 초급 상위. **러시아 시민권 신청 최소 언어 요건**.

## 1. 개요

주관·체계·5 subtests·66% 합격 기준 — 상세는 [A1 문서](./a1.md) 참조.

### A2 (ТБУ) 특수 활용
- **러시아 연방 시민권 신청** 최소 언어 요건 (Федеральный закон о гражданстве РФ)
- **러시아 연방 영주권(ВНЖ) 신청** 언어 요건
- 러시아 대학 **예비 과정(факультет / подготовительное отделение)** 입학 준비
- ※ 단, 러시아 대학 학부 정규 과정 입학은 **B1 (ТРКИ-I) 이상** 필수

## 2. A2 능력 정의

공식 **Базовый уровень 능력 기준**:

- 일상 경험 영역(가족·쇼핑·직장·근교·도시 내 이동) 빈번 표현 이해
- 친숙 일상 주제 간단 직접 정보 교환
- 과거·현재·계획된 미래 활동 간단 서술
- 간단한 공식 상황(우체국·은행·약국·병원) 대응

## 3. 학습 범위

### 문법 핵심 (A1 위에 추가)
- **격 체계 완성**: 6격 전체
  - Именительный (주격)
  - Родительный (생격) — 소유·부정·수량
  - Дательный (여격) — 간접목적·대상
  - Винительный (대격) — 직접목적
  - Творительный (조격) — 수단·동반
  - Предложный (전치격) — 장소·주제
- 명사 **변화(склонение)** 3식 체계 숙달
- 형용사 성·수·격 일치
- 대명사 전 격 변화
- **동사상(вид)** 본격: НСВ (несовершенный вид) vs СВ (совершенный вид)
- 동사 **이동(глаголы движения)**: идти/ходить, ехать/ездить, нести/носить, вести/водить, везти/возить 등 무접두사·접두사 동사
- 미래시제 (простое·сложное)
- 명령법 (повелительное наклонение)
- 복문 접속사: потому что, поэтому, если, когда, что

### 어휘 수량
공식 대강: **약 1,300단어** (ТБУ 최소 어휘 사전).

### 어휘 주제
A1 확장 + 쇼핑·식당, 여행·호텔, 건강·병원, 취미·여가, 감정, 교육·학업, 러시아 문화·지리 기초

### 누적 학습 시간
**약 180~200 수업시간** (누적).

## 4. 시험 구성

### 5개 subtests (구조 A1과 동일)

| Субтест | 시간 | 배점 |
|---|---|---|
| 1. Лексика·Грамматика | 약 60분 | 100점 |
| 2. Чтение | 약 50분 | 100점 |
| 3. Аудирование | 약 30분 | 100점 |
| 4. Письмо | 약 50분 | 100점 |
| 5. Говорение | 약 30분 | 100점 |

총 약 **3시간 40분**, 2일 분할.

### 문제 유형
A1과 유사 구조, 난이도·길이·복잡성 상승.

## 5. 채점·합격 기준

- 각 subtest **66/100 이상** 동시 충족
- 미달 subtest 부분 증서(Справка), 2년 내 재응시
