# TORFL C1 (ТРКИ-III / Third Certification) 심층 가이드

> TORFL 고급. **러시아 어문학·언어학 전공 학위 취득 최소 기준**. 전문직 인증.

## 1. 개요

주관·체계 — [A1 문서](./a1.md) 참조. CEFR C1.

### ТРКИ-III 특수 활용
- **러시아 대학 어문학(филология)·언어학(лингвистика) 전공** 학사·석사·박사 학위 취득 기준
- **러시아어 번역·통역 전문직** 자격
- **러시아어 저널리즘·편집** 전문직
- **국제관계·경영·외교** 실무 고급
- 러시아 고위 관료·경영진 언어 인증
- 한국 대학 러시아어 전공 교원 임용

## 2. C1 능력 정의

공식 **Третий сертификационный уровень 능력 기준**:

- 광범위·요구도 높은 장문 텍스트 암시적 의미까지 이해
- 뚜렷한 단어 검색 없이 유창·자발적 표현
- 사회·학술·전문 목적 언어 유연·효과적 사용
- 복잡 주제 명확·잘 구조화된·상세한 텍스트 산출
- 언어학·번역·편집·저널리즘·국제관계·경영 등 전문 활동 수행 가능

## 3. 학습 범위

### 문법·언어 운용 핵심
- 전 문법 체계 숙달 + 미묘한 뉘앙스
- 문어체·격식체 vs 구어체·비격식체 정밀 선택
- 수사법 (метафора, метонимия, ирония, гипербола, эвфемизм)
- 고급 관용 표현·속담 (пословицы·поговорки·фразеологизмы)
- 담화 구조·응집성 장치
- 다양한 등록: научный, официально-деловой, публицистический, художественный, разговорный
- 고급 Nominalisation
- 전문 어휘 (법률·경제·과학·문학 비평·언론)
- 지역 변이·역사적 변이 이해

### 어휘 수량
공식 대강: **약 12,000단어** (ТРКИ-III 최소 어휘).

### 어휘 주제
추상 사상·철학, 사회학·심리학, 경제·금융, 법률·행정, 과학·의학, 문학·예술 비평, 역사·정치, 국제 관계, 러시아 문화·지성사

### 누적 학습 시간
**약 1,200~1,500 수업시간** (누적).

## 4. 시험 구성

### 5개 subtests

| Субтест | 시간 | 배점 |
|---|---|---|
| 1. Лексика·Грамматика | 약 90분 | 150점 (100점 환산) |
| 2. Чтение | 약 75분 | 150점 |
| 3. Аудирование | 약 35분 | 100점 |
| 4. Письмо | 약 75분 | 100점 |
| 5. Говорение | 약 40분 | 150점 |

총 약 **5시간 15분**, 2일 분할.

### 문제 유형

**Лексика·Грамматика**: 고급 문법·어휘 변환 전 범주

**Чтение**: 장문·학술·문학·평론 (800~1,500단어 지문, 복수)

**Аудирование**: 강연·토론·문학 낭독·라디오 (복잡 속도, 일부 1회)

**Письмо**: 
- 학술·공식 텍스트
- 논설·평론·보고서
- 약 300단어 이상

**Говорение**:
- 심화 주제 발표
- 전문 분야 토론
- 매개(медиация) — 자료 해석·재구성

## 5. 채점·합격 기준

- 각 subtest **66% 이상** 동시 충족
- 미달 subtest 부분 증서, 2년 내 재응시

## 7. 학습 로드맵

1. **1~8주**: B2 취약점, 학술·저널리즘 등록 선행
2. **9~40주**: C1 교재 (『Русский язык на продвинутом этапе』, 『Прогресс』, 『В эфире - Россия』)
3. **41~52주**: 학술 논문·Коммерсантъ·Новая газета (해외판) 정독, 라디오 강연 청취
4. **53~64주**: 공식 ТРКИ-III 모의 8~10회분, 작문·Говорение 집중
5. 시험 직전 6주: 원어민 튜터 첨삭 필수

### 권장 보조 자료
- **신문·잡지**: Коммерсантъ, Ведомости, Русский репортёр, Эксперт
- **라디오**: Радио Свобода (한국 청취), BBC Russian
- **문학**: Достоевский, Толстой, Солженицын, Шолохов, Битов, Пелевин, Улицкая
- **학술지**: Вопросы литературы, Новое литературное обозрение
