# TORFL A1 (ТЭУ / Elementary) 심층 가이드

> Тест по русскому языку как иностранному (ТРКИ, Test of Russian as a Foreign Language — TORFL) 최하위 등급. 러시아어 입문자 대상.

## 1. TORFL 개요

### 주관
**러시아 연방 교육과학부** (Министерство науки и высшего образования РФ) 공인. 주요 시행 기관:
- 국립 **푸쉬킨 러시아어 연구소** (Государственный институт русского языка им. А.С. Пушкина)
- **상트페테르부르크 국립대학교** (СПбГУ)
- **모스크바 국립대학교** (МГУ)
- **러시아 민족우호대학** (РУДН / RUDN University)
- **톰스크 국립대학교** (ТГУ)

### 체계 (6 레벨 / CEFR 대응)
| TORFL | 러시아명 | 약칭 | CEFR |
|---|---|---|---|
| Elementary | Элементарный уровень | **ТЭУ** | **A1** |
| Basic | Базовый уровень | **ТБУ** | **A2** |
| First | Первый сертификационный уровень | **ТРКИ-I** | **B1** |
| Second | Второй сертификационный уровень | **ТРКИ-II** | **B2** |
| Third | Третий сертификационный уровень | **ТРКИ-III** | **C1** |
| Fourth | Четвёртый сертификационный уровень | **ТРКИ-IV** | **C2** |

### 5 subtests (모든 레벨 공통)
1. **Лексика·Грамматика** (어휘·문법)
2. **Чтение** (독해)
3. **Аудирование** (청해)
4. **Письмо** (작문)
5. **Говорение** (구술)

### 합격 공통 원칙
**각 subtest 66% 이상** 동시 충족. 한 subtest 미달 시 총점 무관 불합격.

### 학위 특성
- **유효기간 무기한** (평생)
- 러시아 교육부 공식 인정
- 러시아 대학·비자·시민권·취업 등 공식 증명

### 2022년 이후 변화
러시아-우크라이나 전쟁 후 일부 국가에서 시험장 운영 제한. 한국은 시행 지속 중 (일부 시험장 일시 중단 공지 확인 필요).

## 2. A1 (ТЭУ) 능력 정의

공식 **Элементарный уровень 능력 기준**:

- 일상 극히 친숙한 표현·기본 문장 이해·사용
- 자기·타인 소개, 거주지·국적·가족·직업 정보 질의응답
- 숫자·시간·날짜·가격 이해·표현
- 상대가 천천히·명확히 말하면 매우 간단한 소통 가능

## 3. 학습 범위

### 문법 핵심
- **키릴 알파벳** (33자) 쓰기·읽기 완성
- 명사 **성(род)**: мужской/женский/средний
- 명사 **수(число)**: единственное/множественное
- **격(падеж) 체계 입문**: Именительный (주격), Винительный (대격 생물·무생물 구분), Предложный (전치격, 장소 표현)
- 대명사 기초: я/ты/он/она/оно/мы/вы/они + 소유 мой/твой/наш/ваш
- 동사 현재형 기초 (1식·2식 변화)
- 동사 과거형 기초 (성·수 일치)
- 동사상 입문 — НСВ/СВ (불완료/완료상) 개념 인지
- 기초 전치사: в/на + 전치격·대격, у + 생격
- 의문사: кто, что, где, когда, как, почему, сколько
- 숫자 0~1000, 순서수

### 어휘 수량
공식 대강: **약 780단어** (ТЭУ 최소 어휘 사전 기준).

### 어휘 주제
인사·소개, 가족, 숫자·시간·날짜·요일·월, 국적·직업, 색깔, 음식·음료, 신체, 옷, 집·가구, 교통, 날씨, 일상 동작, 쇼핑 기초

### 누적 학습 시간
CEFR 권장 **약 100~120 수업시간**. 한국인은 키릴 알파벳·격 체계 장벽으로 초기 시간 증가.

## 4. 시험 구성

### 5개 subtests

| Субтест | 시간 | 배점 |
|---|---|---|
| 1. Лексика·Грамматика | 약 50분 | 100점 환산 |
| 2. Чтение | 약 45분 | 100점 환산 |
| 3. Аудирование | 약 30분 | 100점 환산 |
| 4. Письмо | 약 50분 | 100점 환산 |
| 5. Говорение | 약 30분 | 100점 환산 |

**총 시험 시간**: 약 **3시간 30분**, 통상 **2일에 걸쳐 진행**.
- **1일차**: Письмо, Лексика·Грамматика, Чтение
- **2일차**: Аудирование, Говорение

### 문제 유형

**Лексика·Грамматика** (어휘·문법)
- 빈칸 채우기 (격·동사 변화·전치사)
- 객관식 문법 선택

**Чтение** (독해)
- 짧은 메시지·공지·양식·광고
- 객관식 내용 이해

**Аудирование** (청해)
- 짧은 대화·공지·메시지 (2회 청취)
- 객관식

**Письмо** (작문)
- 양식 채우기
- 짧은 메시지·엽서 (30~40단어)

**Говорение** (구술)
- 자기소개 · 개인 정보 대화
- 사진·상황 기반 짧은 발화
- 시험관과 역할극

## 5. 채점·합격 기준

### 배점·합격선
- 각 subtest **100점** 환산
- **각 subtest 66/100 이상** (66%) 동시 충족 필요

### 부분 합격
미달 subtest가 있으면 **부분 증서(Справка)** 발급. 통상 **2년 이내 미달 subtest만 재응시** 가능.

### 유효기간
전체 합격 증서(Сертификат) **무기한 유효**.

## 7. 학습 로드맵

1. **1~4주**: 키릴 알파벳 완성, 발음·강세(ударение) 규칙
2. **5~16주**: A1 교재 (『Дорога в Россию 1』, 『Поехали! 1』, 『Русский с азов』)
3. **17~20주**: 격 체계 입문 (주격·대격·전치격 용법 구분)
4. **21~24주**: 공식 TORFL A1 모의시험 (Государственный институт русского языка им. А.С. Пушкина 제공) 3~5회분
5. 시험 직전 2주: Говорение 모의
