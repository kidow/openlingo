# TORFL B2 (ТРКИ-II / Second Certification) 심층 가이드

> TORFL 중·상급. **러시아 대학 학사·석사·박사 학위 취득 기준** (어문학 제외).

## 1. 개요

주관·체계 — [A1 문서](./a1.md) 참조. CEFR B2.

### ТРКИ-II 특수 활용
- **러시아 대학 학사·석사·박사 학위 취득** 언어 요건 (어문학·언어학 계열 제외)
- **일반 전공** 학위 수여 기준
- 러시아 전문직 취업 기초
- 러시아·국제기구 실무직 지원

## 2. B2 능력 정의

공식 **Второй сертификационный уровень 능력 기준**:

- 구체·추상 주제 복잡 텍스트 주요 요지 이해 (전문 분야 기술 논의 포함)
- 원어민과 자연스러운 유창성·자발성으로 상호작용
- 다양한 주제로 명확·상세한 텍스트 산출
- 문화·학술·전문 영역에서 폭넓은 의사소통 수행

## 3. 학습 범위

### 문법 핵심 (B1 위에 추가)
- 전 격 체계 자유 구사 (의미·뉘앙스 완전 숙달)
- 형동사·부동사 능동 사용·쓰기
- 복합 관계절 구조
- 간접화법 정밀 변환
- 가정법 복잡 용법 (бы 구문 전반)
- 조건문 전 유형
- 수사학적 수단: 어순 변화(инверсия), 강조 구문
- 전문 등록(стиль): 과학·공식·신문·구어
- 조어법 심화 (접두사·접미사·복합어 생성 규칙)
- 동사상 세부 (одновидовые·двувидовые глаголы)

### 어휘 수량
공식 대강: **약 6,000단어** (ТРКИ-II 최소 어휘).

### 어휘 주제
사회·정치·경제 일반, 환경·생태, 과학·기술, 매체·저널리즘, 교육 제도, 문화 비평, 국제 관계, 러시아 현대 사회

### 누적 학습 시간
**약 720~900 수업시간** (누적).

## 4. 시험 구성

### 5개 subtests

| Субтест | 시간 | 배점 |
|---|---|---|
| 1. Лексика·Грамматика | 약 90분 | 150점 (100점 환산) |
| 2. Чтение | 약 60분 | 150점 |
| 3. Аудирование | 약 35분 | 100점 |
| 4. Письмо | 약 60분 | 100점 |
| 5. Говорение | 약 35분 | 150점 |

총 약 **4시간 40분**, 2일 분할.

### 문제 유형

**Лексика·Грамматика**: 복잡 문법 변환·빈칸 (전 범주)

**Чтение**: 장문 독해 — 신문 사설·학술 기사·문학 (500~800단어 지문 다수)

**Аудирование**: 강연·뉴스·토론·라디오 발췌 (1~2회)

**Письмо**:
- 공식 서한·보고서
- 기사·요약·의견문
- 약 200~250단어

**Говорение**:
- 제시 자료 독해 후 대화
- 문제 해결·의견 개진
- 지속 대화 (시험관과)

## 5. 채점·합격 기준

- 각 subtest **66% 이상** 동시 충족
- 미달 subtest 부분 증서, 2년 내 재응시

## 7. 학습 로드맵

1. **1~4주**: B1 취약점, 형동사·부동사 능동 사용 전환
2. **5~28주**: B2 교재 (『Дорога в Россию 4』, 『Пятый этаж』, 『Точка Ру B2』)
3. **29~40주**: 신문 사설 정독, 라디오·팟캐스트 청취, 작문 구조 훈련
4. **41~52주**: 공식 TORFL-II 모의 10회분, 장문 요약·의견문 훈련
5. 시험 직전 4주: Говорение 심화 주제 파트너 연습
