# JLPT N3 심층 가이드

> 일본어능력시험 중급 입문. 초급(N4·N5)과 중·상급(N2·N1) 사이 **브리징 레벨**. 2010년 개편 시 신설.

## 1. 레벨 정의

공식 **N3 능력 기준**:

- **종합**: 일상적인 장면에서 쓰이는 일본어를 어느 정도 이해할 수 있는 수준.
- **읽기**: 일상 화제의 구체적 내용을 나타내는 문장을 읽고 이해. 신문 기사 제목 등에서 정보의 개요를 파악. 일상 접하는 난이도가 다소 높은 문장도 달리 표현된 힌트가 주어지면 요지를 이해.
- **듣기**: 일상 장면에서 거의 자연스러운 속도로 진행되는 대화를 들어 구체적 내용·등장인물 관계를 거의 이해.

CEFR 기준 대체로 B1 초반 수준 (비공식 참고).

## 2. 학습 범위 (업계 추정치)

| 항목 | 누적 수량 |
|---|---|
| 한자 | 약 650자 |
| 어휘 | 약 3,700단어 |
| 문법 항목 | 약 200개 (N3 고유 약 100개) |

### N4 대비 핵심 추가
- **경어 체계화**: 존경어·겸양어·정중어 구분 및 대표 동사 (いらっしゃる, おっしゃる, 召し上がる, 伺う 등)
- **복합 문법**: ～ということ, ～わけ, ～はず, ～べき, ～ため, ～間(に), ～うちに, ～とおり, ～ばかり, ～たばかり, ～ところ(계열)
- **조건·양보 심화**: ～ても, ～としても, ～にしても
- **기능어**: ～わけではない, ～ないこともない, ～に違いない, ～かもしれない
- 신문·뉴스체 수동 표현

### 누적 학습 시간 (제로 스타트)
600~1,200시간. N4 완성자는 추가 300~600시간.

## 3. 시험 구성

| 섹션 | 시간 |
|---|---|
| 언어지식(문자·어휘) | 30분 |
| 언어지식(문법)·독해 | 70분 |
| 청해 | 40분 |
| **총 시험 시간** | **140분** |

### 문제 유형 카테고리

**언어지식(문자·어휘)**
- 한자 읽기
- 표기
- 문맥 규정
- 유의 표현
- 용법

**언어지식(문법)·독해**
- 문법 형식 판단
- 문장 완성
- 문장 흐름
- 내용 이해(단문) — 150~200자
- 내용 이해(중문) — 350자 정도
- 내용 이해(장문) — 550자 정도
- 정보 검색

**청해**
- 과제 이해
- 포인트 이해
- 개요 이해 (N3부터 추가)
- 발화 표현
- 즉시 응답

## 4. 채점·합격 기준

### 득점 구분 (N3부터 3개 섹션 분리)

| 섹션 | 배점 |
|---|---|
| 언어지식(문자·어휘·문법) | 0–60점 |
| 독해 | 0–60점 |
| 청해 | 0–60점 |
| **총점** | **0–180점** |

### 합격 조건

1. **종합 합격점**: **95점 / 180점 이상**
2. **섹션별 기준점**: 각 섹션 **19점 / 60점 이상**

한 섹션이라도 19점 미달 시 총점 무관 불합격. 척도득점 적용.

## 6. 학습 로드맵 예시

1. **1~4주**: N4 취약점 복습, 경어 체계 선행 학습
2. **5~16주**: N3 종합 교재 (『新完全マスター N3』 5권 세트: 문법·독해·청해·어휘·한자)
3. **17~24주**: 영역별 문제집 반복, 신문 기사 제목·짧은 사설 읽기
4. **25~28주**: 공식 문제집 + 과년도 기출 + 청해 집중 (개요 이해 유형 대비)
