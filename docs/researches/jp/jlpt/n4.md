# JLPT N4 심층 가이드

> 일본어능력시험(日本語能力試験) 초급 상위 등급. 기초 일본어 완성 단계.

## 1. 레벨 정의

공식 JLPT **N4 능력 기준**:

- **종합**: 기본적인 일본어를 이해할 수 있는 수준.
- **읽기**: 기본적인 어휘와 한자로 쓰인 일상적 화제의 문장을 읽고 이해.
- **듣기**: 일상 장면에서 다소 느리게 진행되는 대화면 거의 내용을 이해.

CEFR 기준 대체로 A2 수준에 대응 (비공식 참고).

## 2. 학습 범위 (업계 추정치, 공식 리스트 없음)

| 항목 | 대략적 수량 |
|---|---|
| 한자 | 약 300자 (누적) |
| 어휘 | 약 1,500단어 (누적) |
| 문법 항목 | 약 150개 (누적) |

### N5 대비 핵심 추가 학습
- 동사 활용 전반: て형, た형, ない형, 가능형, 의지형(よう형), 명령형, 조건형(ば·たら·と·なら), 수동·사역·사역수동
- 형용사 활용 (과거·부정·て형)
- 수수동사: あげる/くれる/もらう
- 경어 기초 (정중체 중심)
- 복문 접속사: から, ので, のに, けれど, が
- 인용 と, 전문 そうだ, 추측 ようだ·みたいだ·らしい
- 조건 표현 4종 비교

### 누적 학습 시간 추정 (제로 스타트)
300~600시간.

## 3. 시험 구성

| 섹션 | 시간 |
|---|---|
| 언어지식(문자·어휘) | 25분 |
| 언어지식(문법)·독해 | 55분 |
| 청해 | 35분 |
| **총 시험 시간** | **115분** |

### 문제 유형 카테고리

**언어지식(문자·어휘)**
- 한자 읽기
- 표기
- 문맥 규정
- 유의 표현
- 용법

**언어지식(문법)·독해**
- 문법 형식 판단
- 문장 완성 (어순)
- 문장 흐름
- 내용 이해(단문) — 100~200자
- 내용 이해(중문) — 450자 정도
- 정보 검색 — 안내·공지문

**청해**
- 과제 이해
- 포인트 이해
- 발화 표현
- 즉시 응답

## 4. 채점·합격 기준

### 득점 구분

| 섹션 | 배점 |
|---|---|
| 언어지식(문자·어휘·문법)·독해 | 0–120점 |
| 청해 | 0–60점 |
| **총점** | **0–180점** |

### 합격 조건

1. **종합 합격점**: **90점 / 180점 이상**
2. **섹션별 기준점**:
   - 언어지식·독해: **38점 / 120점 이상**
   - 청해: **19점 / 60점 이상**

단 한 섹션이라도 기준점 미달 시 총점 무관 불합격. 척도득점(IRT 기반) 적용.

## 6. 학습 로드맵 예시

1. **1~8주**: N5 완성 복습 + 동사 활용 전반 체계화
2. **9~20주**: 『みんなの日本語 初級 II』 혹은 동급 교재 완독
3. **21~28주**: N4 전용 문제집 (『新完全マスター N4』, 『TRY! N4』, 『日本語総まとめ N4』)
4. **29~32주**: 공식 샘플 + 과년도 모의시험 + 청해 집중 (청해 난이도 상승)
