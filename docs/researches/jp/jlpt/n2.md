# JLPT N2 심층 가이드

> 일본어능력시험 중·상급. 실무 일본어 입문선. 일본 취업·유학 실용 기준선으로 흔히 요구됨.

## 1. 레벨 정의

공식 **N2 능력 기준**:

- **종합**: 일상적 장면의 일본어 이해에 더해, 보다 폭넓은 장면의 일본어를 어느 정도 이해할 수 있는 수준.
- **읽기**: 신문·잡지의 기사·해설, 평이한 평론 등 논지가 명확한 문장을 읽고 내용을 이해. 일반 화제 서적을 읽고 이야기 흐름·표현 의도를 이해.
- **듣기**: 일상·폭넓은 장면에서 자연스러운 속도에 가까운 대화·뉴스를 들어 이야기 흐름·내용·등장인물 관계·요지를 이해.

CEFR 기준 대체로 B2 수준 (비공식 참고).

## 2. 학습 범위 (업계 추정치)

| 항목 | 누적 수량 |
|---|---|
| 한자 | 약 1,000자 |
| 어휘 | 약 6,000단어 |
| 문법 항목 | 약 370개 (N2 고유 약 170개) |

### N3 대비 핵심 추가
- **기능어 대량 확장**: ～ものの, ～つつ(も), ～ながらも, ～にもかかわらず, ～にせよ, ～とはいえ, ～だけあって, ～ばかりか, ～どころか, ～限り, ～以上(は), ～上で, ～上に, ～反面, ～際, ～に際して, ～に当たって, ～をきっかけに, ～を通じて, ～をめぐって
- **표현 뉘앙스 분화**: 원인·이유(～ものだから, ～あまり, ～おかげで, ～せいで), 강조(～てならない, ～てたまらない, ～てしかたがない)
- **경어 운용 숙련**: 비즈니스 장면 기초
- **논설·사설 독해**: 추상 어휘, 역접·인과 구조 파악
- **청해**: 뉴스·강의체, 간접 표현, 정중체 회의

### 누적 학습 시간 (제로 스타트)
1,200~2,400시간. N3 완성자는 추가 600~1,200시간.

## 3. 시험 구성

| 섹션 | 시간 |
|---|---|
| 언어지식(문자·어휘·문법)·독해 | 105분 |
| 청해 | 50분 |
| **총 시험 시간** | **155분** |

※ N2부터 언어지식과 독해가 **단일 시험지로 통합**(3개 득점 섹션은 별도 채점).

### 문제 유형 카테고리

**언어지식(문자·어휘)**
- 한자 읽기
- 표기
- 단어 형성
- 문맥 규정
- 유의 표현
- 용법

**언어지식(문법)**
- 문법 형식 판단
- 문장 완성 (어순 배열)
- 문장 흐름

**독해**
- 내용 이해(단문) — 200자 정도
- 내용 이해(중문) — 500자 정도
- 내용 이해(장문) — 900자 정도
- 통합 이해 — 복수 텍스트 비교
- 주장 이해(장문) — 논설·평론 900자 정도
- 정보 검색 — 광고·팸플릿 700자 정도

**청해**
- 과제 이해
- 포인트 이해
- 개요 이해
- 즉시 응답
- 통합 이해

## 4. 채점·합격 기준

### 득점 구분

| 섹션 | 배점 |
|---|---|
| 언어지식(문자·어휘·문법) | 0–60점 |
| 독해 | 0–60점 |
| 청해 | 0–60점 |
| **총점** | **0–180점** |

### 합격 조건

1. **종합 합격점**: **90점 / 180점 이상**
2. **섹션별 기준점**: 각 섹션 **19점 / 60점 이상**

한 섹션이라도 19점 미달 시 총점 무관 불합격. 척도득점(IRT) 적용.

## 6. 실용적 활용

- 일본 기업 채용 서류전형 기본 요건으로 자주 명시 (특히 개발·IT 외 일반 직무).
- 일본 전문학교·일부 학부 입학 최소선.
- 한국 기업 일본어 특기자 전형에 흔히 활용.

## 7. 학습 로드맵 예시

1. **1~4주**: N3 취약점 복습, 신문 기사 매일 1편 정독
2. **5~20주**: N2 종합 교재 (『新完全マスター N2』 5권 / 『日本語総まとめ N2』)
3. **21~32주**: 영역별 심화 — 기능어 패턴 암기, 장문 독해 시간 단축 훈련
4. **33~40주**: 공식 문제집 + 과년도 기출 5회분 이상 + 청해 뉴스체 청취 (NHK 뉴스 등)
5. 시험 직전 2주: 실전 타이머 모의고사, 약점 섹션 집중
