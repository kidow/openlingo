# JLPT N1 심층 가이드

> 일본어능력시험 최고 등급. 학술·전문·추상 영역 포함 폭넓은 장면에서 사용되는 일본어를 이해.

## 1. 레벨 정의

공식 **N1 능력 기준**:

- **종합**: 폭넓은 장면에서 사용되는 일본어를 이해할 수 있는 수준.
- **읽기**: 신문 사설·평론 등 논리적으로 다소 복잡하고 추상도가 높은 문장을 읽고 문장의 구성·내용을 이해. 다양한 화제의 내용이 깊은 읽을거리를 읽고 이야기 흐름·상세 표현 의도를 이해.
- **듣기**: 자연스러운 속도의 체계적인 회화·뉴스·강의를 들어 이야기 흐름·내용·등장인물 관계·내용의 논리 구성 등을 상세히 이해하며 요지를 파악.

CEFR 기준 대체로 C1 수준 (비공식 참고).

## 2. 학습 범위 (업계 추정치)

| 항목 | 누적 수량 |
|---|---|
| 한자 | 약 2,000자 (상용한자 수준) |
| 어휘 | 약 10,000단어 |
| 문법 항목 | 약 570개 (N1 고유 약 200개) |

### N2 대비 핵심 추가
- **고급 기능어**: ～べからず, ～まじき, ～ずにはおかない, ～ずにはすまない, ～てやまない, ～を余儀なくされる, ～を禁じ得ない, ～きらいがある, ～が早いか, ～や否や, ～そばから, ～なり, ～つ～つ, ～ともなく, ～ともなれば, ～とあって, ～とあれば, ～ものを, ～にかたくない, ～にたえる／たえない, ～の至り, ～の極み
- **문어체·한어 다용**: 신문 사설, 평론, 학술 논문 어휘
- **관용구·사자성어**: 고사성어, 속담, 비유 표현
- **경어 심화**: 이중 경어 회피, 자연스러운 비즈니스·공식 장면 구사
- **추상 논설 구조 분석**: 필자 주장·근거·반론 구조, 암시·풍자·아이러니 해석
- **청해**: 강의체, 토론, 인터뷰, 방언 일부, 빠른 구어, 생략 표현

### 누적 학습 시간 (제로 스타트)
2,400~4,800시간. N2 완성자는 추가 1,200~2,400시간.

## 3. 시험 구성

| 섹션 | 시간 |
|---|---|
| 언어지식(문자·어휘·문법)·독해 | 110분 |
| 청해 | 55분 |
| **총 시험 시간** | **165분** |

※ N2와 동일 구조 — 시험지 통합·3개 섹션 별도 채점.

### 문제 유형 카테고리

**언어지식(문자·어휘)**
- 한자 읽기
- 문맥 규정
- 유의 표현
- 용법
(표기·단어 형성은 N1에서 생략되는 경우 있음)

**언어지식(문법)**
- 문법 형식 판단
- 문장 완성 (어순 배열)
- 문장 흐름

**독해**
- 내용 이해(단문) — 200자 정도
- 내용 이해(중문) — 500자 정도
- 내용 이해(장문) — 1,000자 정도
- 통합 이해 — 복수 텍스트 (600자 정도)
- 주장 이해(장문) — 논설·평론 1,000자 정도
- 정보 검색 — 700자 정도

**청해**
- 과제 이해
- 포인트 이해
- 개요 이해
- 즉시 응답
- 통합 이해

## 4. 채점·합격 기준

### 득점 구분

| 섹션 | 배점 |
|---|---|
| 언어지식(문자·어휘·문법) | 0–60점 |
| 독해 | 0–60점 |
| 청해 | 0–60점 |
| **총점** | **0–180점** |

### 합격 조건

1. **종합 합격점**: **100점 / 180점 이상** (최고선, 득점률 약 55.6%)
2. **섹션별 기준점**: 각 섹션 **19점 / 60점 이상**

한 섹션이라도 19점 미달 시 총점 무관 불합격. 척도득점(IRT) 적용 — 원점수 정답률과 일치하지 않음.

## 6. 실용적 활용

- 일본 대학원·연구직 지원 필수선에 근접.
- 일본 의료·법무 등 국가자격 전제 조건 (예: 후생노동성 일본어 시험의 대체 인정 등 일부 경로).
- 일본 내 통역·번역·교직 관련 포지션 기준선.
- 한국 내 일본 대기업·종합상사·법무법인 선호.

## 7. 학습 로드맵 예시

1. **1~4주**: N2 취약점 정리, 신문 사설 매일 정독 (아사히·요미우리 천성인어 등)
2. **5~24주**: N1 종합 교재 (『新完全マスター N1』 5권 / 『日本語総まとめ N1』) 전권 순회
3. **25~40주**: 영역별 심화 — 고급 기능어 570개 패턴 내재화, 장문 독해 속도·정확도 훈련
4. **41~48주**: 공식 문제집 + 과년도 기출 10회분, NHK 뉴스·라디오 강연 청취 (1.25배속)
5. **시험 직전 4주**: 실전 타이머 모의고사 주 2회, 약점 섹션(흔히 독해 시간 압박) 집중

### 권장 보조 자료
- NHK ニュース, クローズアップ現代
- 아사히 「天声人語」, 마이니치 「余録」 (사설 독해)
- 신초샤·이와나미 문고 수필집 (문어체 독해)
- 青空文庫 (고전 어휘 확장)
