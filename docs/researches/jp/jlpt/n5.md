# JLPT N5 심층 가이드

> 일본어능력시험(日本語能力試験, Japanese-Language Proficiency Test) 최하위 등급. 기초 일본어 입문자 대상.

## 1. 레벨 정의

공식 JLPT(국제교류기금·일본국제교육지원협회)가 규정하는 **N5 능력 기준**:

- **종합**: 기본적인 일본어를 어느 정도 이해할 수 있는 수준.
- **읽기**: 히라가나·가타카나 및 일상 기본 한자로 쓰인 정형화된 어구·문장·문단을 읽고 이해.
- **듣기**: 교실·신변 등 자주 접하는 장면에서 천천히 진행되는 짧은 대화에서 필요한 정보를 알아들음.

CEFR 기준 대체로 A1 수준에 대응 (비공식 참고).

## 2. 학습 범위 (비공식 추정치, 공식 리스트 없음)

공식 입장: **어휘·한자 리스트 비공개** (특정 리스트 암기 학습을 권장하지 않음). 다만 실제 출제 경향 기반 업계 통용 추정치:

| 항목 | 대략적 수량 |
|---|---|
| 한자 | 약 100자 |
| 어휘 | 약 800단어 |
| 문법 항목 | 약 80개 (조사, 기본 활용, ます/です형 등) |

### 필수 선행 학습
- 히라가나·가타카나 전수 습득 (쓰기·읽기)
- 숫자, 시간, 요일, 날짜 표현
- 기본 조사: は, が, を, に, で, と, も, の, へ
- 동사 3그룹 분류 및 ます형
- 형용사 い/な형
- 지시사 これ/それ/あれ, ここ/そこ/あそこ

### 누적 학습 시간 추정 (제로 스타트)
150~300시간. 일본어 한자권 비이용자(영어권) 기준 업계 통용 수치. 한국인은 한자·어순 친숙도로 단축 가능.

## 3. 시험 구성

공식 시간표·섹션 구분:

| 섹션 | 시간 |
|---|---|
| 언어지식(문자·어휘) | 20분 |
| 언어지식(문법)·독해 | 40분 |
| 청해 | 30분 |
| **총 시험 시간** | **90분** (입실·주의사항 제외, 실제 체류 약 105분) |

### 문제 유형 카테고리 (공식)

**언어지식(문자·어휘)**
- 한자 읽기
- 표기 (히라가나→한자)
- 문맥 규정
- 유의 표현

**언어지식(문법)·독해**
- 문법 형식 판단
- 문장 완성 (어순 배열)
- 문장 흐름
- 내용 이해(단문) — 80자 정도
- 내용 이해(중문) — 250자 정도
- 정보 검색 — 안내문·알림 등

**청해**
- 과제 이해
- 포인트 이해
- 발화 표현
- 즉시 응답

## 4. 채점·합격 기준

### 득점 구분

| 섹션 | 배점 |
|---|---|
| 언어지식(문자·어휘·문법)·독해 | 0–120점 |
| 청해 | 0–60점 |
| **총점** | **0–180점** |

※ N4·N5는 문자·어휘·문법·독해가 **통합 1개 섹션**.

### 합격 조건 (2개 모두 충족 필요)

1. **종합 합격점**: 총점 **80점 / 180점 이상**
2. **섹션별 기준점** (단 한 섹션이라도 미달 시 총점 무관 불합격):
   - 언어지식·독해: **38점 / 120점 이상**
   - 청해: **19점 / 60점 이상**

### 채점 방식

**척도득점(scaled score)** 사용. 원점수를 문항반응이론(IRT) 기반으로 회별 난이도 차이를 보정한 상대적 득점으로 환산. 정답 수 단순 합산 아님.

## 5. 한국 응시 정보 (2026년 기준)

### 주관
한국일본어능력시험 서울실시위원회 등. 공식 포털: **jlpt.or.kr**.

### 시험 회차
연 2회:
- **제1회**: 7월 첫째 일요일 (2026년 7월 5일)
- **제2회**: 12월 첫째 일요일

### 접수 일정 (2026 제1회 기준)
- 일반접수: 2026-04-01 ~ 2026-04-19
- 추가접수: 2026-04-27 ~ 2026-05-03 (10% 할증)
- 수험표 출력: 2026-05-25 ~ 2026-07-05
- 성적 발표: 8월 말
- 성적증명서 발송: 10월 중순

### 응시료 (2024 기준, 2026 유사 예상)
- **N4~N5**: 60,000원 (추가접수 시 66,000원)
- N1~N3: 75,000원 (참고)

### N5 입실 시간
오후 타임 — 입실 완료 13:40 (N3~N5 공통).

### 시험장
전국 주요 도시 — 서울/부산/대구/광주/대전/인천 등. 접수 시 선택. 영남권은 부산지역 별도 위원회(bsjlpt.or.kr)가 관할.

## 6. 학습 로드맵 예시

1. **1~4주**: 히라가나·가타카나 암기·쓰기 완성
2. **5~12주**: 기본 교재 (예: 『みんなの日本語 初級 I』) 1~25과
3. **13~20주**: N5 전용 종합 문제집 (예: 『新完全マスター N5』, 『日本語総まとめ N5』)
4. **21~24주**: 공식 샘플 문제집 + 과년도 모의시험 반복, 청해 집중
