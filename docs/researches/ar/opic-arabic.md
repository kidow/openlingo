# OPIc Arabic (MSA) 심층 가이드

> **한국 내 유일 상시 응시 가능 아랍어 공인 시험**. ACTFL 주관·한국 크레듀 시행·전국 시험장 운영.

## 1. OPIc 개요

### 주관
- **ACTFL** (American Council on the Teaching of Foreign Languages) — 미국 외국어교육협의회
- **Language Testing International (LTI)** — ACTFL 공식 시험 운영 파트너
- **한국 주관사**: **크레듀(Credu)** — 삼성SDS 자회사 **멀티캠퍼스** 연계

### OPI vs OPIc 차이

| | OPI | **OPIc** |
|---|---|---|
| 형식 | 전화 인터뷰 — 실제 평가자 | **컴퓨터 기반 인터뷰** — 녹음 후 평가자 채점 |
| 소요 시간 | 15~30분 | **20~40분** |
| 응시 환경 | 전화 | 시험장 컴퓨터 |
| 비용 | 고가 ($150~200) | 저렴 (한국 84,000원) |
| 한국 응시 | 제한적 (예약 필요) | **전국 시험장 상시** |

**OPIc**가 한국 표준.

### OPIc 외국어 종류
영어, 중국어, 일본어, 한국어, **아랍어**, 스페인어, 러시아어, 베트남어, 말레이어/인도네시아어, 프랑스어, 독일어, 태국어 등.

### 아랍어 특수사항
**OPIc Arabic = MSA (Fuṣḥā) 전용**. 방언(عامية) 사용 금지. Modern Standard Arabic 표준 구사 필수.

## 2. ACTFL 10단계 레벨

| 등급 | 약칭 | 설명 | CEFR 대응 |
|---|---|---|---|
| Superior | S | 최상위, 원어민 학술 수준 | C2 |
| Advanced High | AH | 복잡 주제 유창 | C1~C2 |
| Advanced Mid | AM | 대부분 주제 능숙 | C1 |
| **Advanced Low** | **AL** | 구체·추상 주제 능숙 | B2~C1 |
| Intermediate High | IH | 친숙 주제 유창 | B2 |
| Intermediate Mid | IM | 일상 주제 의사소통 | B1 |
| Intermediate Low | IL | 간단 상호작용 | A2~B1 |
| Novice High | NH | 친숙 주제 단문 | A2 |
| Novice Mid | NM | 기초 단어·구 | A1 |
| Novice Low | NL | 최초 단계 | Pre-A1 |

### AL 이상 의미
- **AL**: ACTFL 기준 "복잡 과제 능동 수행" — 실질적 업무 가능선
- 한국 취업 시장에서 **IH·AL** 목표가 일반
- 2026년부터 **일부 외국어 OPIc 응시 자격에 AL 보유** 도입 (공식 공지)

## 3. 시험 구성

### 기본 형식
- **컴퓨터 기반(CBT)** 인터뷰
- 지정 시험장 내 독립 부스
- 헤드셋·마이크 착용
- 약 **20~40분 녹음**
- 사전 **Background Survey** (12문항) + **Self Assessment** (6단계 난이도 선택)

### 질문 구성
1. **자기소개·배경**
2. **Survey 응답 기반 맞춤 질문**: 본인·가족·직장·학업·취미·관심사
3. **일반 주제**: 여행·음식·영화·운동·계절
4. **Role Play** (역할극) 2~3개: 특정 상황에서 대응
5. **돌발 질문**: 상위 레벨 평가용

### 레벨 판정
사전 Self Assessment 선택 + 답변 질·다양성·길이·복잡도 종합 평가.

## 4. 채점·결과

### 채점
- 녹음본 **ACTFL 인증 평가자 1~2인** 채점
- 언어별 전문 채점자 배정
- 아랍어: MSA 평가자 배정

### 결과
- 10단계 중 하나 판정
- **합격·불합격 개념 없음** — 실제 언어 수준을 특정 레벨로 인증
- 결과 통보: 시험 후 **3~7 영업일**

### 유효기간
- OPIc 증서 공식 유효기간 규정 없음
- 단 **한국 기업·취업 활용 시 보통 2년 이내** 성적 요구

### 재응시 제한
- 한국: **하루 1회, 연간 25회** 응시 가능 (공식 규정)
- 같은 날 중복 불가

## 5. 한국 응시 정보 (2026)

### 주관·접수
- **공식 사이트**: opic.or.kr
- **크레듀** 회원가입·접수
- 시험장 선택 (전국 지정 컴퓨터 시험장)

### 응시료 (2024 기준)

- 2026 확정가 opic.or.kr 실시간 확인

### 시험장
전국 수십 곳 (서울·경기·부산·대구·광주·대전·울산 등). 주요 학원·교육기관 내 OPIc 지정 시험장.

- 2026-01-01부터 **OPIc 시행 외국어 응시자 AL 이상 보유 요건** 도입 공지 (공식 사이트)
- 아랍어 포함 적용 여부·구체 범위는 공식 공지 직접 확인 필수

### 준비물
- 신분증 (주민등록증·운전면허증·여권)
- 접수 확인증 (모바일·프린트)

## 6. 학습 로드맵

### IL~IM 목표 (초급)
1. **1~8주**: MSA 알파벳·발음·기초 문법 (『Alif Baa』, 『Al-Kitaab Part 1』 1~10과)
2. **9~16주**: 일상 주제 회화 (인사·가족·직장·취미)
3. **17~20주**: OPIc Survey 예상 질문 스크립트 작성·암기
4. **시험 직전 2주**: 모의 녹음 훈련

### IH~AL 목표 (중·고급)
1. **1~16주**: 『Al-Kitaab Part 2·3』 중심
2. **17~32주**: MSA 뉴스(Al Jazeera·BBC Arabic) 청취·발음 모방
3. **33~40주**: 시사·사회·문화 주제 확장, 논증적 발화 연습
4. **41~44주**: OPIc 모의 시험 10회 이상 녹음·자기 평가
5. 시험 직전 4주: 원어민 튜터 피드백

### 핵심 전략
- **Background Survey 전략적 선택**: 답변 가능 주제 12개 선택 — 본인 강점 주제 집중
- **Self Assessment 레벨 적절 선택**: 너무 높으면 어려운 질문, 낮으면 레벨 판정 한계
- **Role Play 대비**: 호텔 예약·식당 주문·길 묻기·불만 제기 등 상용 패턴 암기
- **MSA 문법 정확성**: 남·여 동사 변화, 명사 성·수·격 일치, 동사 시제 체계
- **발음**: ع·ح·ق·خ·غ·ص·ض·ط·ظ 등 한국인 어려운 자음 집중

### 권장 보조 자료
- **교재**: 『Al-Kitaab』 시리즈 (Georgetown), 『Mastering Arabic』 (Wightwick)
- **뉴스**: Al Jazeera Arabic, BBC Arabic, Al Arabiya
- **팟캐스트**: ArabicPod101, Kalam 팟캐스트
- **유튜브**: Learn Arabic with Maha, Easy Arabic
- **앱**: Memrise Arabic, Rocket Arabic

## 7. 활용

- **한국 대기업 취업·승진** 외국어 스펙 (삼성·현대·SK·LG 등)
- **공공기관 채용** 외국어 가산점 (외교부·KOTRA·공공 외신 관련)
- **아랍어권 주재원·법인 근무** 언어 증명
- **중동·북아프리카 무역·건설·에너지** 분야
- 대학 졸업·대학원 지원 외국어 증명
- **AL 이상**: 아랍어 전공 교원·전문 통번역 활용 가능
