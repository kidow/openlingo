# ALPT (Arabic Language Proficiency Test) 심층 가이드

> **온라인 컴퓨터 적응형 아랍어 인증 시험**. Arab Academy(카이로) 주관. 한국에서 온라인 상시 응시 가능한 대안.

## 1. 개요

### 주관
- **Arab Academy** — 1996년 설립, 이집트 카이로 소재 아랍어 교육·평가 기관
- **Islamic Chamber of Commerce and Industry (ICCI)** — 이슬람 상공회의소 공식 인정
- 2002년 이후 ALPT 시험 운영

### 위상
- 세계 아랍어 학습자 온라인 표준 인증 중 하나
- 학교·대학·기관 **배치고사·모니터링** 용도 널리 활용
- 한국 내 공식 오프라인 대안 부재 시 주요 선택지

### 시험 형식
- **Computer-Adaptive Test (CAT)** — 응시자 정답률에 따라 문항 난이도 실시간 조정
- **온라인 전용** — 인터넷 연결 컴퓨터에서 어디서나 응시
- Arab Academy 웹 서버 호스팅

### 평가 기술 (5개)
1. **Listening Comprehension** (청해)
2. **Reading Comprehension** (독해)
3. **Structure** (어휘·문법)
4. **Writing** (작문)
5. **Speaking** (구술, 실제 강사와 인터뷰)

### MSA 표준
ALPT는 **MSA (Modern Standard Arabic / Fuṣḥā)** 평가. 방언 포함 안 됨.

## 2. 레벨 체계

### CEFR 대응
ALPT 결과는 **CEFR A1~C2**로 환산·해석. 학교·기관·고용주가 이해하기 쉬운 형식.

| CEFR | ALPT 수준 설명 |
|---|---|
| A1 | 기초 인사·개인 정보 |
| A2 | 일상 친숙 주제 간단 대화 |
| B1 | 여행·업무 기본 의사소통 |
| B2 | 복잡 주제 이해·상세 표현 |
| C1 | 유창·효과적 전문 운용 |
| C2 | 원어민 수준 학술·전문 |

## 3. 시험 패키지 3종

### 패키지 1: Essential Skills
- Listening + Reading + Structure (문법·어휘)
- 객관식 위주
- 자동 채점 (즉시 결과)
- 가격대: 저렴

### 패키지 2: Fundamental Skills
- Essential Skills + **Writing**
- 작문 과제 추가 (주관식)
- 강사 채점 단계 포함

### 패키지 3: Comprehensive
- Fundamental Skills + **Speaking**
- 아랍어 강사와 **온라인 구술 인터뷰**
- 전 5 기술 종합 평가
- 가장 완전한 인증

### 구성 세부
- **처음 3개 파트 (Listening/Reading/Structure)**: 객관식 CAT
- **4번째 파트 (Writing)**: 개방형 주관식
- **5번째 파트 (Speaking)**: 아랍어 교사 실시간 인터뷰 (화상·전화)

## 4. 채점·결과

### 채점 방식
- CAT 섹션: 즉시 자동 채점
- Writing: Arab Academy 강사 채점
- Speaking: 인증 평가자 채점
- 종합: CEFR 레벨 + 세부 영역 점수

### 결과 문서
- **온라인 인증서** (디지털 PDF)
- 영역별 점수 표기
- CEFR 레벨 종합 판정

### 유효기간
명시 규정 없음. 통상 2년 이내 활용 권장.

### 재응시
제한 없음. 언제든 재응시 가능 (단, 응시료 별도).

## 5. 응시 방법

### 접수
- **arabacademy.com** 온라인 가입
- 패키지 선택
- 결제 (국제 카드·PayPal)

### 응시 환경
- 인터넷 연결 컴퓨터
- 웹캠·마이크 (Speaking 인터뷰용)
- 조용한 공간
- 집·사무실 어디서나

### Speaking 인터뷰 예약
- Comprehensive 패키지 응시자만
- Arab Academy 강사와 시간 조율
- 화상 통화 (Zoom·Skype·자체 플랫폼)
- 15~30분

### 응시료 (참고)
- Essential: 약 USD 50~80
- Fundamental: 약 USD 80~120
- Comprehensive: 약 USD 120~180
- 환율·프로모션에 따라 변동. 공식 사이트 실시간 확인.

## 6. 한국 응시자 특이사항

### 장점
- **한국 어디서나 응시 가능** (집·사무실·카페)
- 별도 시험장 방문 불필요
- 응시료 저렴
- 결과 신속 (Essential은 즉시)

### 단점
- **국내 인지도 낮음** — 한국 대기업·공공기관 공식 인정 드묾
- 국제 대학·글로벌 기업 위주 인정
- OPIc 대비 한국 취업 시장 가치 낮음
- 부정응시 방지 장치 약함

### 권장 대상
- 아랍어 학습 수준 **자가 측정**
- 아랍 국가 대학 지원 시 보조 증빙
- 국제 NGO·UN·유엔 기구 지원 보조 인증
- **공식 취업 스펙** 목적이면 **OPIc Arabic 병행** 권장

## 7. 학습 로드맵

### 단기 자가 측정 (시험 이전 1~2개월)
1. **Essential Skills** 응시로 현재 레벨 파악
2. 약점 영역 파악 후 집중 보강

### 장기 인증 획득
1. **1~6개월**: MSA 기초 (『Alif Baa』, 『Al-Kitaab 1』) 완성
2. **7~12개월**: Intermediate 수준 (『Al-Kitaab 2·3』)
3. **13~18개월**: Fundamental 패키지 응시 (B1~B2 목표)
4. **19~24개월**: Comprehensive 패키지 응시 (Speaking 포함)

### 권장 보조 자료
- Arab Academy 자체 온라인 강좌
- 『Al-Kitaab』 시리즈 (Georgetown)
- Madinah Arabic (무료 온라인)
- Al Jazeera Arabic 뉴스
- BBC Arabic

## 8. 한계·주의

- **한국 공공기관·대기업 공식 인정 제한적** — 취업 활용 시 OPIc 병행 권장
- 온라인 응시로 부정행위 통제 약함 → 일부 기관 가치 낮게 평가
- **IAEA·UN·ISO 등 국제 표준 ISO 17024 공인 여부 확인 필요**
- Speaking 평가 강사 평가 일관성 — 강사 경력별 편차 가능
