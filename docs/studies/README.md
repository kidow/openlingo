# 학습 기록

이 폴더는 실제로 공부한 내용을 언어별, 날짜별로 남기는 복습용 지식 베이스입니다.

## 구조

```text
docs/studies/<lang>/<YYYY-MM-DD>.md
```

예시:

```text
docs/studies/ja/2026-04-25.md
docs/studies/en/2026-04-25.md
docs/studies/zh-hans/2026-04-25.md
```

## 역할 구분

- `docs/studies/`: 실제로 공부한 내용의 날짜별 기록
- `src/content/notes/`: 언어별 참고 메모
- `docs/researches/`: 외부 자료 조사와 언어별 리서치

## 작성 규칙

- 문서는 한국어로 작성합니다.
- 새 기록을 만들기 전에 같은 언어와 같은 날짜의 파일이 있는지 확인합니다.
- 같은 날짜 파일이 있으면 새 파일을 만들지 않고 기존 파일에 덧붙입니다.
- 언어 폴더명은 프로젝트에서 사용하는 언어 코드를 따릅니다.
- 파일명은 `YYYY-MM-DD.md` 형식을 사용합니다.
- 실제로 공부한 내용, 예문, 헷갈린 점, 복습할 것을 우선 기록합니다.
